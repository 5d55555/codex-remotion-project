# 资料与复核

- `受苦时间线.md`、`转刺客途径.md`、`外号与名场面.md`：第一轮资料整理。
- `复核.md`：逐条复核。**冲突时以复核为准**，主要修正：
  - 奥萝尔从背后出手不在第一卷第79章，而在第101章《不同的能力》，而且是循环梦境里被怪物控制的她；卢米安自己说“刚才那个不是奥萝尔，是被怪物控制的她！”（第102章）。
  - 封印在左胸的是奥萝尔及周围信徒、祭品的灵魂残片和污染力量，封印者是佛尔思信奉的“愚者”（第一卷第109章）；体内的“忒尔弥波洛斯”后来揭晓早已被阿蒙取代（第五卷第141、142章）。
  - 每天凌晨六点重置身体状态是正文（第一卷第109章，佛尔思说）。
  - 第五卷：仪式是“让超过三万人卷入一场剧烈的瘟疫”，不是要三万人全死；性别“以最高的那个序列为准”（第14章）；成为“绝望魔女”后身体确为女性（第145章）；跳回“猎人”可以重新变成男人（第149章）。
  - “真要是自己选择的……”是芙兰卡的内心判断；“为什么非得安排我？”是卢米安的内心疑问；“变成失控的‘旧日支配者’”是叙述。
  - 变狗（造畜之术）是卢米安自己用来潜入的，片中标“自愿·不计”。
  - “被逼开始一段‘魔女’人生”是作者第五卷卷末总结的原话。
