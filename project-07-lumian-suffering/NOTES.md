# 卤面受苦实录（《宿命之环》卢米安·李）

## 文件

- `src/manga.tsx`：纸面、网点、集中线、分格、拟声字、对话框、旁白框、出处条、正字计数、印章、卷标、血点。
- `src/lumian.tsx`：Q 版卢米安（黑色短碎发、浅蓝眼睛，八种表情，可加兜帽、创可贴、冷汗、黑线、长发）与奥萝尔剪影。
- `src/props.tsx`：思考云、闹钟、闪电、裂纹、阿蒙剪影（尖帽、单片眼镜）、封印纹、狗皮、肩上的脑袋、风暴、回忆小窗、报告纸。
- `src/scenes/page.tsx`：一页漫画的骨架（卷标、计数、翻页）；`a.tsx`、`b.tsx`：各页。
- `scripts/make_score.py`：番剧式配乐与音效（记一笔、翻页、滑哨、失败长号等），按段内帧号卡点。
