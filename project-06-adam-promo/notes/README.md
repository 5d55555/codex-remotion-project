# 资料与复核

- `身份.md`、`事件线.md`、`台词与主题.md`：第一轮资料整理。
- `复核.md`：逐条复核与年表。**冲突时以复核为准**，主要修正：
  - 《“保命咒语”》在第七部《倒吊人》第53章，不是第八部；“亚当已借助之前的全面战争晋升序列0”是克莱恩写下的分析前提。
  - 亚当饮下魔药的场景在第六部《逐光者》第116章《光》，由叙述者直接描写（白袍、淡金胡须的神父饮下金黄色魔药）。
  - 世界大战在乔治三世死前（1350年10月）已经爆发，国王死后（1350年12月）才全面扩大；1352年初战神陨落、战争结束。
  - 第五部第90章三句话的归属：“成神仪式就是让时代的发展符合自己的空想？”“等到时代浪潮滚滚而来……”是克莱恩的内心推断；“在规定的时代潮流中，服食魔药晋升？”出自罗塞尔日记。
  - 第五部第87章《要有光》里金色眼睛的男子是远古太阳神的历史影像，不是第五纪的亚当。
  - 亚当成神前能核实的原话：第四部第213章“很可惜，没能留住那条蛇。”“所有命运的馈赠，早已在暗中标注好了价格，不是吗？”；第五部第203章“这样的结局，你接受吗？”
  - 大雾霾年份、开战日期、乔治三世身亡月份据 Wiki；伤亡数字是第五部第88章奥黛丽回想的报纸初步统计。
