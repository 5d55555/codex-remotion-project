# 资料与复核

- `天尊.md`、`上帝.md`、`战争.md`、`源质.md`：第一轮资料整理，每条标了【正文】【设定集】【Wiki】【读者】。
- `复核一.md`、`复核二.md`：对片中要上屏的说法逐条复核。**和第一轮冲突时以复核为准**，主要修正：
  - 黑夜女神解释这场战争的章节是《诡秘之主》第八部《愚者》第十六章《大手笔》，不是第一卷（第一卷第十六章叫《狗拿耗子》）。
  - “第一纪中期……最终双双陨落？”是克莱恩的内心推想；女神说战斗细节没谁知晓，额外源质令本能失控时用了“应该”。
  - “源质是象征的集合……”是佛尔思说的；“正常而言，源质和唯一性一样，不可分割……只有一种情况能造成它们的撕裂，那就是遇上最初那位造物主时”是愚者说的。
  - 《神性与人性》是第七卷第五十四章：天尊是源堡的化身、原初上帝是混沌海的象征、天尊容纳过永暗之河与失序之国，都是愚者明言；上帝容纳过灾祸之城是愚者的推测。失序之国对应仲裁人、律师，另据起点设定集。
  - “上帝从天尊身上撕下‘错误’”是克莱恩的推断；女神给的信息是上帝尸骸在混沌海形成第一块亵渎石板，旁边存在偷盗者途径唯一性。
  - 不眠者途径的序列0叫“黑暗”（黑夜女神是神灵称号）；魔女途径序列0在设定集里有“魔女”“原初魔女”两种写法。
  - 漩涡脸出自《宿命之环》第八卷《永劫者》第七章《选择》，是特定场景的显现，不能当作原初上帝的固定样貌。
  - 时间措辞不统一：克莱恩推想“第一纪中期”，女神说掌握额外源质在“第一纪中前期”，愚者说天尊陨落前封印源质在“第一纪中后期”，佛尔思说“第一纪末”（不保证正确）。片中不把它们合并成一个日期。
