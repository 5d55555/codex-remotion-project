# 天尊 vs 上帝 · 第一纪支柱之战（推演）

横屏 1920×1080、30fps、185 秒（5550 帧），段与段之间硬切。画风与前几部都不同：宇宙尺度的神战，深空星野；天尊是灰雾凝成、坐于云座的巨像（冕旒遮面、背后光环与源堡），上帝是混沌液体凝成、张开双臂的巨像（头部是没有五官的漩涡，背后放射彩色光芒）；权柄化成发光的大字当兵器对轰。

## 原作能确认什么

- 起因：黑夜女神说“聚合是本能。层次越高，本能越强。”两位都有重新聚合成最初造物主的本能；第一纪中前期各自掌握了额外的、复数的源质，本能“应该”因此失控。（《诡秘之主》第八部《愚者》第十六章《大手笔》）
- 过程：“那场战斗具体的情况怎么样，没谁知晓，就连灵界七光都无从了解。”（同章）——所以片中的打戏全部是推演，片头就这样交代，并全程挂着“推演”角标。
- 双方：天尊是源堡的化身，第一纪容纳过永暗之河、失序之国；原初上帝是混沌海的象征，愚者推测祂容纳过灾祸之城。（《宿命之环》第七卷第五十四章《神性与人性》）
- 结局：天尊陨落前把七份源质（母巢、失序之国、暗影世界、灾祸之城、永暗之河、知识荒野、光之钥）封印到西大陆，由蓬莱看守；两位“近乎同归于尽”。（《宿命之环》第七卷第五十五章《序列之上》）
- 遗留：上帝的尸骸在混沌海形成第一块亵渎石板，旁边是偷盗者途径的唯一性（女神）；“是上帝从天尊身上撕下来的”是克莱恩的推断。

逐条出处与复核见 `notes/`，先看 `notes/README.md`。

## 推演怎么排

每个权柄都对应一条有出处的途径（源质 → 途径 → 序列0 → 领域，领域依据起点设定集），出招顺序和画面是推演：

1. 聚合：两位被拉向彼此，源堡与混沌海显现，第一次碰撞。
2. 源堡对混沌海：风暴（暴君）→ 门（门）把风暴送到上帝背后；愚弄（愚者）→ 太阳（太阳）烧穿灰雾；窃取（错误）→ 心灵（空想家）让偷到的东西在手里炸开。
3. 额外的源质：永暗之河（黑暗、黄昏巨人、死神）→ 灾祸之城（红祭司、魔女，标“愚者推测”）；失序之国（审判者、黑皇帝）锁链与扭曲 → 知识（白塔）读穿律令、堕落（倒吊人）拖拽。
4. 聚合失控：引愚者“只有遇上最初那位造物主时才能撕裂源质”，两位本是那一位的不同人格，越靠越近互相撕扯；“错误”被撕下（标“克莱恩的推断”）。
5. 陨落：七道光封印到西大陆；灰雾散去，上帝沉入混沌海成为第一块亵渎石板；“近乎同归于尽”。

之后是“之后”（五条遗留，全部正文）和“哪些是真的”（正文明写 / 角色推测 / 本片推演三栏）。

## 文件

- `src/bg.tsx`：星空、灰雾、混沌海、雾海与海面。
- `src/figures.tsx`：天尊、源堡、青铜长桌、上帝、漩涡脸；裂纹、消散、闪白、施法姿态。
- `src/fx.tsx`：震屏、闪白、冲击波、权柄字形、出招标签、源质球，以及门、风暴、落雷、光柱、窃取、幻象、长河、火城、锁链、群眼、阴影、雾幕、汇聚、光核。
- `src/text.tsx`：打字机、标签（可加暗底）、电影字幕、角标、大标题。
- `src/scenes/intro.tsx`、`fight.tsx`、`outro.tsx`：各段场景；`src/timeline.json`：时长（重叠为 0）。
- `scripts/make_textures.py`：程序化生成灰雾、混沌海、星空纹理（numpy + PIL）。
- `scripts/make_score.py`：配乐。天尊用五声拨弦、钟、磬、锣，上帝用管风琴与合唱垫，打戏用太鼓、定音鼓、重击与上升音效；按段内帧号卡点，母带前做 15 kHz 低通，避免 AAC 过冲。

## 命令

```bash
npm install
python3 scripts/make_textures.py   # 生成纹理
npm run score                      # 生成配乐
npm run qa -- 1160 2165 3740       # 渲染指定帧的静帧
npm run build                      # 渲染 out/tianzun-vs-god.mp4
```
