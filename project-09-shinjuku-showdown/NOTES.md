# 新宿決戦（project-09）

五条悟 vs 两面宿傩「人外魔境新宿决战」（原作第 221–236 话）的像素风同人短片：1920×1080、60fps、197.17 s，配乐是游戏里的原曲（不剪不改）。
角色用游戏 `android-shinjuku` 的像素纸娃娃，背景、立绘、特效、文字都是这里程序化合成的，没有用任何动画原片画面。

## 怎么做出来

| 步骤 | 命令 | 产物 |
|---|---|---|
| 像素部件 | `python3 scripts/export_sprites.py` | `public/sprites/*.png`、`src/data/sprites.json`（关节点、眼睛位置） |
| 背景 / 立绘 | `python3 scripts/make_plates.py <Luna 原图目录>` | `public/plates/*`、`public/portraits/*`（原图不进仓库） |
| 静帧检查 | `node scripts/qa.mjs 帧号…`，`python3 scripts/sheet.py OUT.jpg 帧号…` | `out/qa/` |
| 音效提示 | `node scripts/cues.mjs` | `out/cues.json`（各镜头 `cues` 汇总） |
| 合成音效 | `python3 scripts/sfx.py` | `out/sfx.wav` |
| 混音 | `bash scripts/mix.sh` | `out/mix.wav`（-14 LUFS / -1 dBTP） |
| 渲染 | `bash scripts/render.sh [幕号…]` | 分幕 `out/parts/actN.mp4` → 无损拼接 `out/silent.mp4` |
| 封装 | 见下 | `out/新宿決戦.mp4` |

封装：`ffmpeg -i out/silent.mp4 -i out/mix.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k -ar 48000 -movflags +faststart -metadata title=新宿決戦 out/新宿決戦.mp4`

## 画面管线（src/engine）

- **每帧只由帧号决定**（Remotion 多标签乱序渲染）：粒子按出生时间解析计算，不做逐帧模拟；随机数是整数哈希。
- **相机**：世界坐标 = 角色像素（脚底 y=0）；`z` = 一个角色像素占几个屏幕像素。故事板的倍数按 55 像素的小人定，`Stage.zoomBoost` 再统一推近 1.3 倍，远景镜头自己设回 1。
- **像素层**：角色画在低分辨率画布上（部件旋转用最近邻，跟游戏一样的锯齿），再整体最近邻放大，亚像素平移让慢摇镜头不跳格。
- **背景**：绘画背景按深度 `d` 做视差；平视镜头用 `anchor()` 每帧把图上的地面点钉在角色脚下，所以推拉时脚不滑。图盖不满的地方：街道把路面镜像接下去，其它图按需要放大。
- **高清特效**（fx.ts）：苍、赫、茈、光束、黑闪、斩线、冲击波、火花、碎块、烟尘、结界球与裂纹、八辐车轮、信息流、雪、余烬、浮尘……都在全分辨率上画。
- **后期**（Stage.finish）：1/4 分辨率阈值 + 模糊做辉光，去饱和 / soft-light 调色，暗角，胶片颗粒，遮幅，负片冲击帧，红蓝色差。`slice()` 把画面沿一条线切开错位（“解”切背景、世界斩切整个画面）。
- **文字**（src/text.tsx）：竖排毛笔咏唱（Yuji Syuku）、招式名（Zen Antique）、日中双语台词字幕、内心独白、片名。字体由 `scripts/glyphs.mjs` 收集用到的字，渲染前一次加载。

## 成片

- `out/新宿決戦.mp4`：1920×1080、60fps、H.264 High（CRF 16 / preset slow，约 30 Mbps）、BT.709、AAC 320k；音频 -14 LUFS、真峰值约 -2.5 dBFS。
- `out/新宿決戦_15M.mp4`：同一母版两遍编码到 15 Mbps（约 360 MiB），用于发送（对话里上传上限 400 MiB，母版 722 MiB 发不出去）。
- 闪光检查（`python3 scripts/flashcheck.py out/silent.mp4`）：全片相邻帧亮度跳变 ≥20% 的有 31 处，任意 1 秒内最多 1 次来回闪，低于 WCAG 每秒 3 次的上限。
- 分幕渲染约 4–5 帧/秒（4 核），全片约 45 分钟。

## 已知取舍

- 原作的世界斩前并没有当场咏唱；这里为了让观众看懂，先切开画面，再用宿傩插镜补上「龍鱗 · 反発 · 番いの流星」。
- 机场里的故人没有像素素材，只拍五条和空座位。
- 五条被斩只用画面错位、剪影和遮幅表达，不画血和断面。
