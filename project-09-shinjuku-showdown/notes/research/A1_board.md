**容易翻车的点与解决办法**

| 风险 | 解决办法 |
|---|---|
| **55px角色放大后，像素粗糙被误当成画质差** | 角色采用最近邻采样，背景与辉光高清渲染；运动以角色像素网格为基础。近景看姿态与眼光，特写优先拍轮、球、剑线，不持续怼脸。 |
| **“8×头像占半屏”与55px全身尺寸冲突** | 按给定尺寸，8×全身约440px，头像不可能占1080高度的一半。因此本表最高6×，不依赖头部超大特写；需要情绪时用构图与负空间。 |
| **推拉过程中像素大小抖动** | 角色先在固定低分辨率层渲染，再统一放大；角色与背景用同一相机位移。慢推尽量短，关键姿势停在清晰像素对齐位置。 |
| **纸娃娃拳击像挥舞木板** | 每次重击采用“前倾预备→臂角快速变化→接触停2–3帧→整身后移”的顺序。冲击重量来自整体位移、残影与镜头反应，不要求肘腕细节。 |
| **没有手指仍硬拍结印** | 用两臂胸前重叠、逆光遮合和术式环完成识别。世界斩结印使用主观剪影插镜，不展示可供检查的手部。 |
| **前56秒过长、人物像站桩** | 每4小节至少改变一个明确状态：地点揭示、帐、增幅、姿势、咏唱、红蓝合流、城市受光。术式规模必须持续增长，不能仅靠镜头慢推。 |
| **黑闪、领域、茈全部靠全屏闪白，既疲劳又失去层次** | 黑闪主要压暗背景并在接触点闪红黑；领域用色相与空间转换；只有茈使用大面积亮场。禁止连续逐拍全屏闪白；保留低闪光导出版。 |
| **所有重击都震屏，动作读不清** | 普通拳击只短位移2–4屏幕像素；建筑撞击6–10px；最大爆炸主要靠环境运动。震屏迅速衰减，文字层不跟着抖。 |
| **五轮领域压缩后像重复开关灯** | 保留五个可辨节点：第一次外壳被破；第二次重开；第三次缩小；第四次域内互殴；第五次五条先完成。镜36承担两轮匹配叠化，其余不混在同一闪光里。 |
| **车轮转太多次，破坏适应规则的观感** | 只在指定拍点转，不把它当节拍器。领域段与后续体术段用重新出现的轮盘建立阶段变化；不加“每转一次完成25%”之类数值说明。 |
| **顎吐突然消失、观众不知道谁清场** | 镜53明确交代顎吐被强化苍吞没，同时把苍留在战场，直接为下一幕铺垫。 |
| **三打一看不清攻击者** | 固定三个攻击方位，并让三次攻击错开到不同拍：剑线、上方压击、远处细斩。禁止三种特效在同一帧达到峰值。 |
| **世界斩与普通解看起来一样** | 普通解是线穿过物体、物体局部错位；世界斩先让整个画面坐标断开，连天空与漂浮尘土一起移动。 |
| **“勝った”后立刻咏唱，观众来不及读** | “勝った”独占完整1小节；世界斩咏唱采用累积三行字卡并跨镜保留。避免把三个短卡各闪一下。 |
| **机场段音乐仍有能量，所谓“安静”不成立** | 让画面、角色与音效安静，保留配乐本身。用稳定长镜承受音乐余势；不擅改歌曲结构。 |
| **冬日阴天突然成为黄昏** | 在爆炸余光散去时逐渐把云底染暖，机场回来才完成落日色。它是时间压缩后的视觉过渡，不暗示战斗只持续197秒。 |
| **音效掩盖已有电子乐的Drop** | 低频只保留少数主爆点，普通击打以中高频瞬态为主。第一轮验收先完全关掉音效，确认画面本身已经卡住音乐。 |
