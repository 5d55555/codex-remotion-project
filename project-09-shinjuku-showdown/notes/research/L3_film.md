# 制作方案：3 分钟像素风《新宿决战》短片

先校准一下节奏：**143 BPM 下，4/4 的一小节约 1.678 秒，16 小节约 26.85 秒**。三分钟是 180 秒，约 **6.71 段**，不是整整 7 段。建议全片设为 **10,800 帧（1920×1080、60fps）**；用 7 段各约 26.85 秒会得到约 188 秒。更顺手的剪法是 **6 段完整 16 小节 + 最后一段约 11 小节**，总长约 180 秒。若希望每段都完整 16 小节，可把片长定在约 188 秒。

下面给的是可直接拿来做分镜和程序化动画的起步参数。它们是制作建议，不是对 MAPPA 原始作画数据的测量；战斗动画的具体帧数应按镜头重量、音乐和阅读清晰度微调。

## 1. 动画打戏手法，以及像素动画实现

MAPPA 第二季的几场战斗可以作为**镜头语言参考**：五条与甚尔的战斗偏个人对决和突然改变距离；宿傩与魔虚罗的战斗经常将近身冲突、环境破坏和更大尺度的运动交替呈现；宿傩与漏瑚则可以参考火焰和领域带来的强烈色彩对比。MAPPA 第二季导演五条悟（Shōta Goshozono）等人在 Anime Expo 2024 谈过该季动画制作，并展示了分镜相关内容。[Anime Expo 2024 第二季讨论会报道](https://animefire.com/2024/07/21/jujutsu-kaisen-season-2-discussion-at-anime-expo-2024/) 可把它当制作背景资料；以下具体拍法是对这些作品常见视觉效果的**创作性拆解**，不是对某个镜头逐帧定量分析。

| 手法 | 适合用在什么地方 | 60fps 像素/程序动画的起步做法 |
|---|---|---|
| **全景建立空间** | 交代新宿街区、两人距离、建筑破坏规模 | 先给 30–60 帧相对稳定的宽镜头。背景分成近、中、远层，分别以角色位移的约 0.15、0.4、0.7 倍反向移动，制造视差。 |
| **中景对峙 → 特写** | 眼神、咒力蓄势、招式判断 | 中景停留 24–48 帧；特写切入时可做 4–8 帧快速推近，然后停 12–24 帧。像素角色保持锐利，光效层可以更柔。 |
| **快速推拉或横摇** | 突进、闪避、追击、冲击波掠过 | 用 3–6 帧完成 5–10% 的画面位移或缩放。强运动时可让背景横移比角色快，角色位置变化较小，避免画面糊成一团。 |
| **冲击帧 / 黑白反转** | 最重要的拳击、斩击、领域碰撞 | 命中点用 1–2 帧黑白或反色；相邻画面可留白 1–3 帧。不要连续高频闪烁；先让观众读清碰撞方向，再用闪帧强调重量。 |
| **残影 / smear** | 速度爆发、瞬间位移、挥拳、斩击 | 以 1–3 帧绘制拉长或压扁的剪影。角色本体前后保留清晰关键姿势；残影只在路径上留 1–2 个偏移轮廓，透明度递减。 |
| **速度线与拖尾** | 突进和高速横移 | 用 2–6 帧的短线束，在运动方向上拉长。像素线尽量以整数坐标绘制，长度、疏密随速度变，命中时立即截断。 |
| **闪白 / 色彩爆发** | 命中、招式启动、画面转场 | 通常 1–3 帧全屏闪白，之后 4–10 帧迅速退去。小命中只让局部轮廓闪亮；重大招式再用全屏。 |
| **定格与命中停顿** | 让动作有重量，也给观众读图时间 | 角色停住 3–8 帧，强力命中可试 8–12 帧。特效和镜头不一定一同停住：角色冻结、火花继续扩散，会更有层次。 |
| **一拍二拍三拍** | 决定动画密度和情绪 | 60fps 里可分别按每张画 2、3、4 个输出帧来排：一拍二约 30 张/秒、三约 20 张/秒、四约 15 张/秒。快动作密集用一拍二，蓄力和重击前后切到一拍三或四。 |
| **震屏** | 重击、楼体受损、领域展开 | 轻击只晃 1–2 个设计像素、持续 3–5 帧；重击约 3–6 像素、持续 5–9 帧。使用快速衰减的偏移，不要匀速左右摇。 |
| **色调变化** | 攻防局势、术式和段落转折 | 用 6–18 帧把整体彩色层转冷、转暖或压低饱和度；角色轮廓和关键特效维持可读。全片限定一套主色和一套对照色，比每击都换滤镜更统一。 |

### 动作节拍示例：一次重拳命中（共 36 帧，0.6 秒）

- **0–7 帧**：压低重心、肩膀后拉，背景和相机安静。
- **8–13 帧**：快速出拳；拳头 smear 1–2 帧，角色位移逐步加速。
- **14 帧**：单帧黑白冲击帧。
- **15–20 帧**：角色命中停顿 6 帧；火花在这段时间继续扩张。
- **21–26 帧**：受击者向后飞，镜头沿受击方向跟移 3–5 像素。
- **27–35 帧**：速度线消失、碎片落下，落点留出读图时间。

组合时避免把全屏闪白、黑白反转、震屏、残影都堆在同一击上。一次重击通常让其中两三种效果承担重点，其余镜头留白。

## 2. 像素格斗的打击感：一套可调起始值

打击感来自“**预备 → 突发 → 命中 → 反馈 → 回到动作**”的对比，不是单纯增加粒子。有关像素动画的制作资料也强调用攻击轨迹、击中后位移和少量关键帧表现冲击。[像素动画冲击与打击感参考](https://pixeli.pebbly.space/knowledge/rules/81-impacts-and-game-feel) 动作研究也把攻击特效、击中停顿等列为战斗动作视觉化的一部分。[战斗动作特效研究 PDF](https://faculty.washington.edu/zkwen/articles/lin22features.pdf)

| 级别 | 预备 | 命中停顿 | 震屏 | 粒子建议 |
|---|---:|---:|---:|---|
| 轻击 | 3–6 帧 | 2–4 帧 | 1–2 px，2–4 帧 | 2–5 个像素火花，寿命 4–8 帧 |
| 重击 | 6–12 帧 | 5–9 帧 | 3–6 px，5–9 帧 | 6–14 个火花/碎片，寿命 8–18 帧 |
| 决定性碰撞 | 12–24 帧 | 8–14 帧 | 5–10 px，6–12 帧 | 12–30 个分层粒子，寿命 12–30 帧 |

这些是**短片动画的起点**，不是所有格斗游戏的固定规则。动作准备阶段可让身体整体收缩 2–4 像素；命中帧压扁或拉伸角色轮廓；受击后位移 4–12 像素，再以 6–15 帧回弹或进入飞退。粒子分近、中、远三层：近景少量大碎片、中景密集火花、远景尘雾慢扩；每层的亮度和速度不同，空间感会比铺满同一种小点更强。

值得看的案例：

- **《Street Fighter III: 3rd Strike》**：可研究姿态剪影、攻击起落和角色动作的差异。资料常提到其每名角色使用大量手绘帧，但不同角色与招式的实际数量并不应被一个固定数字概括。[Street Fighter III 概览](https://en.wikipedia.org/wiki/Street_Fighter_III)
- **《月下夜想曲》**：适合观察角色轮廓、武器轨迹和场景色彩如何保持哥特式统一。建议把它当美术和轮廓参考，不照搬像素尺寸。
- **《Celeste》**：可参考短促的启动、落地、跳跃反馈，以及画面如何在高频动作中保持清楚。
- **《Hyper Light Drifter》**：参考高饱和攻击色与暗背景的对比、冲刺轨迹和环境粒子。
- **《Octopath Traveler》**：参考低分辨率角色与高清环境光、景深和雾效叠合形成的“像素角色置于立体空间”观感。开发者回顾 HD-2D 的形成时提到，团队在传统点阵画面上研究如何使用 Unreal Engine 表现，最后发展出这种视觉风格。[Fami通开发者访谈](https://www.famitsu.com/news/201807/17160714.html)

## 3. HD-2D 后期和像素清晰度

### 便宜、易控的合成顺序

建议把角色像素帧和高清光效分层渲染：

1. **低分辨率角色层**：例如 320×180 或 480×270，画角色、速度线、近景像素碎片。
2. **高清背景层**：1920×1080，做新宿街景、雾、远处灯光和大面积术式光效。
3. **发光层**：复制高亮区域到独立层，先模糊再以 Screen / Add 方式叠回。
4. **镜头层**：轻微景深、暗角、颜色分级；颗粒和色差只在必要镜头加。
5. **输出层**：最后合成到 1920×1080，60fps。

**景深/移轴：**把背景分成近景、中景和远景，对不同层使用不同强度的模糊；角色和招式核心始终清楚。浅景深可以用来突出眼神、手势或落地，不建议长时间模糊整个战场。廉价方案是把远景单独导出一张纹理图，在 CSS 或 Canvas 上对它施加轻微 blur；需要按深度连续变化时，再考虑 WebGL。

**Bloom：**单独制作低分辨率高亮遮罩，放大并模糊，再叠加回主画面。这样只会让亮区扩散，而不是把整张像素画一起糊掉。优先在离线渲染或 WebGL 中只计算一两级模糊；CSS `filter: blur()` 可作为简单后期方案，MDN 也说明 Canvas 2D 的 `filter` 支持模糊、灰度等滤镜。[Canvas 2D `filter`](https://developer.mozilla.org/en-US/docs/Web/API/CanvasRenderingContext2D/filter)

**体积光：**用一张低分辨率径向渐变或光柱贴图叠在背景后方，以 `screen` 或 `lighter` 混合，再用遮罩限制范围。光柱不要盖住角色眼睛和动作轮廓。

**颜色分级 / LUT：**为每个段落定义一组颜色目标，比如“冷青阴影、暖橙火星”。省时方案是预制一张小型 LUT，用 WebGL shader 查表；不用上 LUT 时，可以在 CSS 或 Canvas 调亮度、对比度、饱和度，但很难精确控制不同亮度区间的颜色。

**暗角、颗粒和色差：**暗角可用一张渐变遮罩；颗粒可用低透明度噪声纹理逐帧换种子；色差只在极短的冲击镜头里将 RGB 通道错开约 1–2 输出像素。它们是收尾调味，应让观众先读到动作。

### 像素放大规则

让每个源像素对应整数个输出像素，可保持硬边清晰：320×180 放大到 1920×1080 正好是 **6 倍**；480×270 放大到 1920×1080 是 **4 倍**。CSS 可写 `image-rendering: pixelated`；MDN 的像素画指南也建议确保放大尺寸匹配整数倍，避免缩放比带来的模糊。[MDN 像素画清晰显示指南](https://developer.mozilla.org/en-US/docs/Games/Techniques/Crisp_pixel_art_look) [MDN `image-rendering`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/image-rendering)

Remotion 中可用 `useCurrentFrame()` 驱动帧序列、相机、停顿、闪帧和粒子；该 hook 返回从 0 开始的当前帧数，适合将上述节奏精确落在帧上。[Remotion `useCurrentFrame()`](https://remotion.vercel.app/docs/use-current-frame)

## 4. 音乐剪辑、文字卡和开结尾

143 BPM 的四拍小节约 **100.7 帧**。剪辑时以实际音乐波形和重拍为准，不要假定所有切点都刚好落在整数帧。可先把歌曲标出小节线、build-up、drop 和停顿，再把动作关键帧对齐到这些标记：

- **小节头**：换景、换构图或启动一组动作。
- **重拍**：拳、斩、落地、标题字出现。
- **副拍**：残影、粒子爆开、角色位移或短促镜头推近。
- **Drop**：安排最清楚、最强的招式画面；让前面的铺垫有空间，不要把高潮效果提前用完。

**Build-up** 可逐渐缩短镜头、加密碎片或让画面颜色逐步收紧；到 drop 前留 6–12 帧纯黑、近静止或低亮画面，制造期待。Drop 后先给一记可读的冲击，再进入连续攻防，避免观众只记得一片闪光。

**文字卡**建议少而准：台词、招式名、章节名分别承担不同功能，不要同时出现。用像素字体承载角色和招式信息，配细小高清副标题或罗马字；先定格画面，再让字以 4–8 帧擦入、打字或跳出。文字避开角色脸部和交手轨迹，并确保移动版也能读清。

**黑场和白场**应当有不同职责：黑场适合蓄势、静默、段落断开；白场适合命中或招式释放。白场可短至 1–3 帧，然后马上回到清楚的画面。开场可以从废墟环境声和远景开始，再在第一段重拍揭示人物；结尾则在最终冲击后留 24–48 帧余韵，使用残烟、碎片或一句短标题收住，不要在最高光效上立刻硬切结束。

## 5. 七段节奏结构与“精致感”清单

如果音乐严格按每段 16 小节，可用下面七段的段落功能来设计，并接受成片约 188 秒。若片长必须控制在约 180 秒，就把最后一段缩成约 11 小节。表内镜头密度是建议范围，指平均每 2–4 秒改变一次构图或视觉重点；动作切点可以更密，但需留出读图时间。

| 段落 | 情绪与画面 | 镜头密度 | 高潮位置 |
|---|---|---|---|
| 1 | 废墟建立、两人对峙，克制、压迫 | 低；远景、眼神特写、静止画面 | 结尾给一次短促的第一次交锋 |
| 2 | 试探与近身，快速但仍可读 | 中；中景交替、少量追镜 | 段末落一次有重量的命中 |
| 3 | 速度升级、闪避与反击 | 中高；横摇、短推镜、残影 | 小高潮放在后 1/3 |
| 4 | 术式蓄势、音乐 build-up，画面减少信息量 | 低到中；特写、静止、色调收束 | Drop 前留一小段静默或暗场 |
| 5 | Drop 后的大规模碰撞或领域级画面 | 高；宽景与特写交替 | 全片主高潮放在中后段，重点画面必须清晰 |
| 6 | 余波、反击和局势变化 | 中；拉回稳定镜头，减少闪帧 | 用一个简洁而明确的反制动作 |
| 7 | 最终对决收束、余韵或标题 | 前密后疏；最后给较长停留 | 结尾 1/3 收束动作，最后留 24–48 帧余韵 |

### 最容易让人觉得“精致”的 10 个细节

1. **动作方向连续**：镜头切换后仍看得懂谁在左、谁在右、攻击往哪边走。
2. **姿态剪影清楚**：冲击帧即使去掉颜色，也能分辨身体朝向和攻击方向。
3. **特效有层次**：大块亮光负责构图，小火星负责质感，尘雾负责空间。
4. **停顿有对比**：强动作之间安排短静止，让每次加速都显得更快。
5. **震屏有衰减**：撞击后迅速停下来，避免摄像机像一直在漂。
6. **角色移动保留像素格**：低分辨率角色尽量在整数像素坐标上移动，减少边缘跳动。
7. **光源有来处**：爆闪、火焰或术式亮起时，同方向的建筑边缘和角色轮廓也短暂受光。
8. **破坏按层次发生**：近景先动、中景跟上、远景最后落灰，比全场同时爆炸更可信。
9. **颜色方案有约束**：每段建立主色与对照色，关键招式才突破配色。
10. **高光效之后留余韵**：让碎屑下落、烟尘散开或角色回到站姿，给观众读出结果的时间。
