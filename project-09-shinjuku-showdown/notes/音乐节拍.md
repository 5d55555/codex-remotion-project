# 配乐节拍（实测）

音源：`android-shinjuku/app/src/main/res/raw/bgm.mp3`，197.17 s，原样使用，不剪不改。

用 120 Hz 低通取底鼓包络，349 个底鼓起音做最小二乘：

- 一拍 **0.426145 s（140.797 BPM）**，第 0 拍在 **0.0144 s**，残差标准差 2.8 ms，全曲无漂移（每 30 秒窗口平均残差在 ±3 ms 内）。
- 先前写的 143.55 BPM 来自 librosa 节拍跟踪的中位间隔，是错的（跟踪器中途丢拍），按它排的小节到 3 分钟时会差出一整拍以上。
- 小节线：Drop 段是四拍底鼓，断层后底鼓回来的位置定为小节第一拍，所以**第 m 小节从第 4m+2 拍开始：t = 0.8667 + 1.70458·m 秒**（开头 0–0.87 s 是两拍弱起）。
