## 哪些是梦（野史）

片子的主线是用户给的野史，片中一律盖红色“梦”章或不盖章：天尊爱而不得、娶不起、没有彩礼、东拼西凑收源质当彩礼；上帝那两份源质“绿了”天尊；拜堂；上帝是个 M；那不是战争而是情趣；天尊玩大了把上帝整死；“不可思议”也救不回完整的支柱（正文没有这条规矩，“不可思议”在正文里只是形容词）；石板上刻的是婚书；聚合倾向让天尊觉得自己在背离上帝；内疚之下把死亡嫁接到自己身上、殉情、化蝶。

“六份彩礼”与“七份封印”的对应是本片的编排：正文只说天尊容纳过永暗之河、失序之国，以及天尊陨落前封印了七份（母巢、失序之国、暗影世界、灾祸之城、永暗之河、知识荒野、光之钥），愚者推测上帝容纳过灾祸之城；片中把其余四份说成“梦里看见的”，把灾祸之城算作上帝那份。
