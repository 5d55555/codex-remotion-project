# 第一纪隐秘历史（梦境占卜所得）

横屏 1920×1080、30fps、222 秒（6660 帧）。皮影戏：油灯在幕后，幕布有布纹和火苗的明暗；人偶是半透明的彩色驴皮（正片叠底），衣服上刻着镂空花纹，关节有铆钉，台下有虚掉的操纵杆。讲述人“本人”一本正经，下方说书板出字；每条说法盖章：黑色“正文”章注明出处，红色“梦”章是野史。

## 角色

- 天尊：老生。玄黄两色（取尊名“福生玄黄”）：黄上衣、黑下裙，刻祥云；道冠、三绺黑髯、胸前太极、拂尘。大袖和拂尘的马尾按胳膊角度反转，始终往下垂。
- 上帝：青衣（正好是这首歌的名字）。混沌海的浪纹、红色云肩、水袖、头面与步摇，脑后一圈慢慢转的光环。
- 最初的造物主：一身两头，左半边天尊、右半边上帝，“分人格”时两半裂开。
- 本人：书生，书生巾，一副不合时代的圆眼镜。

## 结构（对齐音乐）

音乐是用户给的《青衣》DJ版（0.95x，B站 @一支yuuu），约 126 BPM。动画先做，最后接音乐，超出动画的部分剪掉。

## 文件

- `src/stage.tsx`：戏台、幕布、说书板（`Narr`）、证据章（`Seal`）、毛笔大字（`Big`）、戏牌（`ActCard`）。
- `src/puppet.tsx`：皮影骨架（正向运动学算出手的位置接操纵杆；`apart` 让人偶散架）与四个角色。
- `src/props.tsx`：源质圆章、扁担竹篮、绿帽子、囍、红烛、闪电、浪、灰雾、心、亵渎石板、西大陆、蝴蝶、水仙、书案油灯、对话气泡、眼泪。
- `src/scenes/a.tsx`、`b.tsx`：各段；时间都按整片秒数写（`useClock`），方便和音乐对齐。
- `scripts/make_textures.py`：幕布布纹。`scripts/mux.sh`：接音乐。
- 资料与复核见 `notes/`，先看 `notes/README.md`。

## 命令

```bash
npm install
python3 scripts/make_textures.py
npm run qa -- 1980 3870 6240
npm run build      # 出 out/silent.mp4
npm run mux        # 接 public/audio/music.mp3，出 out/dream-history.mp4
```

`public/audio/music.mp3` 是用户提供的音乐，不进仓库。
