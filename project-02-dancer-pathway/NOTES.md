## 舞蹈家的能力与案例（主线内容）

能力：
1. 身体柔韧性大幅提升；晋升还会提升灵性，更容易掌握神秘舞蹈（章节摘要）。
2. 以舞蹈、韵律与灵性调动周围的自然力量，借此向不特定的存在祈祷，产生不同效果；典型舞蹈有“祭舞”“招摄之舞”（摘要）。

案例（均为卢米安·李）：
- 第 80 章《配合》：招摄之舞召来水洼中的怪物，为芙兰卡争取下水寻找镜子的时间（摘要）。
- 第 52 章：招摄之舞尝试让灵附身，读取对方关于剧场女演员的记忆；当时未晋升受契之人（摘要）。
- 第 72 章《祭舞》：祭舞引发异象，体内污染受封印，无法自由调动力量（摘要）。
- 第 83 章《突遇》：已能借祭舞半激发胸口的黑色荆棘符号；仍认为高位格怪物危险（原文）。

代价与限制：仪式后精神疲惫、身体酸痛；招摄之舞有怪物附身的风险；污染受封印（均为摘要）。

## 已知问题与注意事项

1. 生图时，`codex exec` 必须加 `< /dev/null`。否则它会一直停在 `Reading additional input from stdin...`。
2. 生图指令里必须写明“不要 base64、不要用 shell 或 python 转存图片”。否则模型会把图片数据写进 shell 命令，报 `Argument list too long`。
3. 渲染时必须指定浏览器：
   `--browser-executable=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell`
4. 背景图为 940×1672，放大到 1080×1920 会有轻微软化，可以接受。
5. 研究来源多为搜索摘要，部分正文站点是非官方文本站（如 hetushu、biquge、shudugu 等）。正式发布前应对照正式出版版本。
6. 本项目目录尚未提交。远程推送目前返回 403，之前的 `.claude/settings.json` 提交也没有推上去。

## 正式开工时的步骤

1. 用上面的提示词生成 `dancer.png` 和 `ladder.png`（加 `< /dev/null`），复制到 `public/`。
2. `npx tsc --noEmit` 通过后，渲染 6–9 张关键静帧逐一核对。
3. 渲染成片：
   `npx remotion render src/index.tsx DancerPathway out/dancer-pathway.mp4 --browser-executable=<上面的路径>`
4. 用 `ffprobe` 检查时长、分辨率和编码，然后把 MP4 发给用户。
5. 如果用户提供配乐，放入 `public/` 并加上 `<Audio>`，重新渲染。
