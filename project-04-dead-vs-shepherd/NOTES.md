# 逝者 vs 牧羊人 · 像素格斗推演

横屏 1920×1080、30fps、155 秒（4650 帧），段与段之间硬切加闪白。画风刻意与前两部不同：深炭黑擂台、网点与速度线、冷青（逝者）对琥珀（牧羊人）、格斗游戏血条与计时、毛笔印章字。主角是按 Claw'd 比例逐像素画的橙色小怪物，分别穿兜帽斗篷（带尸体脚标）和草帽、牧杖。

## 判断（已与用户确认）

- 正面硬打：牧羊人大概率赢。七个灵魂一次驱使一个、瞬间切换，每魂三种能力在初次放牧时选定；自身还有阴影与血肉魔法，极难杀死。
- 逝者完成假死后可较正常地使用命运能力：窥命，再“说出命运”直接影响对手（腓力曾借此让安东尼陷入恐惧）。有控制和情报，但没有伤害手段，吓住了也打不死。
- 满配的七个灵魂：光之祭司、海洋歌者、秘偶大师、旅行家、看门人、赢家、守护者（全是序列5）。我替牧羊人挑的三种能力专门针对“吓住就跑”：
  - 扛恐惧：光之祭司的免疫恐惧（设定集：作用于自身）。它挡不挡得住“说出命运”，原作没写，片中标了推演。
  - 追：海洋歌者的风之束缚、借风奔跑；守护者的黎明骑士体魄。
  - 堵：旅行家的闪现；看门人的冥界之门；秘偶大师的灵体之线让人迟缓。
  - 旅行家不会自动追踪逃跑的人，冥界之门是“有限度”利用，所以逃跑仍有机会。
- 逝者最优解还是吓住就跑，但成功率比匿名七魂时更低。翻盘需要外来伤害来源（腓力身兼猎人途径收割者），或恐惧正好没被挡住、跑得够远。
- 假死不能当作战斗中的即时“装死逃跑”，原作没有这样的描述。
- 命运推演 82 / 15 / 3（上一版匿名七魂是 70 / 25 / 5）是我的判断，片中已标注“示意推演，不是原作数据”。

依据见 `notes/verify-shepherd.md`、`notes/verify-dead-one.md`（逐场战绩与原文出处），七个灵魂见 `notes/souls/`（先看其中的 README 和出处复核）。

## 结构

cold 冷开场 → title 标题对峙 → p1 / p2 选人卡（技能格 + 六维雷达）→ flock 满配羊圈（七张灵魂卡）→ record 战绩档案 → round1 第一回合（换羊连击：雷击、灵体之线、空气弹；窥命、说出命运、伤害 0；换光之祭司免疫恐惧、挣脱；神圣之光、黎明之剑、引来灾祸）→ ko（K.O.、倒带、窥命看三条支流：闪现堵住 / 冥界之门 / 跑掉）→ sim 命运推演 ×100 → verdict 结论 → gameover。

## 文件

- `src/hud.tsx`：擂台背景、砸字、打字机、故障字、毛笔印章、解说字幕条、血条、计时、雷达、技能格、闪电。
- `src/pixel.tsx`：像素主角（`dead` / `shep` / `plain`）、灵魂羊（七种配饰：光环、音符、提线、门、钥匙、骰子、盾）、花盆；表情有方眼、眨眼、×眼、`> <`。
- `src/souls.ts`：七个灵魂的途径、颜色、定位和三种能力（带出处等级）。
- `src/scenes/a.tsx`、`flock.tsx`、`b.tsx`：各段场景；`src/timeline.json`：时长（重叠为 0）。
- `scripts/make_score.py`：格斗电子 + 芯片音乐配乐，按帧卡点（灵魂卡登场、换羊、命中、恐惧段抽鼓、光柱蓄力、K.O. 留白、倒带、三条支流、推演滴答、GAME OVER）。
