# 逝者 vs 牧羊人 · 像素格斗推演

横屏 1920×1080、30fps、129 秒（3870 帧），段与段之间硬切加闪白。画风刻意与前两部不同：深炭黑擂台、网点与速度线、冷青（逝者）对琥珀（牧羊人）、格斗游戏血条与计时、毛笔印章字。主角是按 Claw'd 比例逐像素画的橙色小怪物，分别穿兜帽斗篷（带尸体脚标）和草帽、牧杖。

## 判断（已与用户确认）

- 正面硬打：牧羊人大概率赢。七个灵魂一次驱使一个、瞬间切换，每魂三种能力在初次放牧时选定；自身还有阴影与血肉魔法，极难杀死。
- 逝者完成假死后可较正常地使用命运能力：窥命，再“说出命运”直接影响对手（腓力曾借此让安东尼陷入恐惧）。有控制和情报，但没有伤害手段，吓住了也打不死。
- 逝者最优解：吓住就跑。翻盘需要外来伤害来源（腓力身兼猎人途径收割者）。
- 假死不能当作战斗中的即时“装死逃跑”，原作没有这样的描述。
- 命运推演 70 / 25 / 5 是我的判断，片中已标注“示意推演，不是原作数据”。

依据见 `notes/verify-shepherd.md`、`notes/verify-dead-one.md`（逐场战绩与原文出处）。

## 结构

cold 冷开场 → title 标题对峙 → p1 / p2 选人卡（技能格 + 六维雷达）→ record 战绩档案 → round1 第一回合（放牧连击、窥命、说出命运、伤害 0、挣脱）→ ko（K.O.、倒带、吓住就跑）→ sim 命运推演 ×100 → verdict 结论 → gameover。

## 文件

- `src/hud.tsx`：擂台背景、砸字、打字机、故障字、毛笔印章、解说字幕条、血条、计时、雷达、技能格、闪电。
- `src/pixel.tsx`：像素主角（`dead` / `shep` / `plain`）与灵魂羊；表情有方眼、眨眼、×眼、`> <`。
- `src/scenes/a.tsx`、`b.tsx`：各段场景；`src/timeline.json`：时长（重叠为 0）。
- `scripts/make_score.py`：格斗电子 + 芯片音乐配乐，按帧卡点（命中、恐惧段抽鼓、K.O. 留白、倒带、推演滴答、GAME OVER）。
