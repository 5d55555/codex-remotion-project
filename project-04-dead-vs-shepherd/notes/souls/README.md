# 七个被放牧的灵魂：资料与复核

满配牧羊人放牧的七个序列5灵魂：光之祭司（太阳）、海洋歌者（水手）、秘偶大师（占卜家）、旅行家（学徒）、看门人（收尸人）、赢家（怪物）、守护者（战士）。

- 每个灵魂一份整理：途径、能力（按序列）、身体素质、与逝者对决相关的判断、代表战例、三选推荐。
- `出处复核.md`：对片中要上屏的说法做了第二轮核查。**两者冲突时以复核为准**，主要修正：
  - 太阳神官的能力名是“免疫恐惧”，设定集写的是作用于自身（同伴加勇气是另一项“太阳光环”）。
  - 风之束缚、借风奔跑（跑速一倍以上）、旅行家的闪现、赢家与灾祸教士的能力，都能在起点设定集查到。
  - 守护者两侧的“无形墙壁”属于序列4猎魔者，不是序列5；片中改用设定集里的“守护”（放弃攻击、强化防御）。
  - 空气弹、纸人替身的系统介绍在第二卷《无面人》第八十三章《魔术师》，不是第一卷。
  - 灵体之线：第三卷《旅行家》第一百八十三章《灵体之线》，刚晋升时初步控制约需20秒。
  - 路德维尔召出青铜大门并连船退走：第三卷《旅行家》第一百七十八章《面具之后》；该场有黑色方戒加持，不全是看门人基础能力。
  - 牧羊人自选三种能力：设定集确认；能否挑低序列能力，目前只有 Wiki 层级的依据。

片中每个灵魂的三种能力见 `src/souls.ts`，是我替牧羊人挑的（推演）。
