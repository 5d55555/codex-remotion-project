# 命运女神途径 · 强度锐评动画

横屏 1920×1080、30fps、约 3 分 21 秒（6030 帧）。画风与工具链沿用 `project-02-dancer-pathway`：旧纸底、红黑线稿、深蓝放射光、章节红卡、底部序列时间轴。全片由代码绘制，底纹与配乐也由脚本生成。

## 主线

强度锐评（个人观点，片中统一用“锐评”徽章标出，与设定事实区分）：

- 序列9—3：孙子；序列2：哥哥；序列1：爹；序列0：爷爷；旧日：列祖列宗。
- 序列9—5 的资料里没有任何身体加成，也没有直接攻击手段；攻击到序列3才有点用。
- 逝者（序列5）对战士途径序列9：依据双方序列描述推演，正面打大概率输，但逝者能假死脱身。

副线：这条途径一路都在失去——失去梦、刺瞎双眼、禁言、假死、反噬致残、无眼者、无头之躯。

## 文件

- `src/brand.ts`：标题、标志、底部时间轴的序列名。组件库 `src/kit.tsx` 从这里读取。
- `src/parts.tsx`：本片专用部件——序列页版式（锐评行：辈分 + 战力星级）、命运之线。
- `src/scenes/a.tsx`、`b.tsx`、`c.tsx`：三章的各张图；`src/scenes/index.tsx` 汇总注册。
- `src/timeline.json`：各段时长，视频与配乐共用。
- `notes/`：研究笔记（途径资料、强度对比依据）与事实核查。

## 命令

```bash
npm install
npm run textures   # 生成底纹
npm run score      # 生成配乐（激昂版，约 45 秒）
npm run qa -- 595 1830
npm run build      # 渲染 out/fate-goddess.mp4
```
