# 宿傩 AI 的四个难度（v0.7）

用户的要求：“给其他难度的宿傩提供AI，不给领域，难度越高，宿傩越聪明，需要会试探和其他。”

做法：Astra 出方案（本文末尾原文）→ 实现 → 自动对战模拟逐项试（`core/src/test/.../AiExperiment.java`，每项开关单独测）→ 用没参与调参的种子验收 → Sol 审计。四个难度的宿傩血量、伤害、招式时间完全一样，只有 AI 不同。

## 每个难度会什么

参数在 `BattleConfig.AiTuning.preset(难度)`，行为在 `SukunaAi.java`。

| 难度 | 宿傩会什么 |
|---|---|
| 三轮（标准） | 基础结构：开展延贴身打，或者在中距离用解试探、攒魔虚罗的适应；看到飞来的招有反应延迟地躲；看到 200% 茈的念咒去打断。和 v0.6 完全一样。 |
| 里梅（困难） | 反应更快、失误更少；进退试探（走近一下不出手再退开）；看到念咒（苍、赫、茈）和瞬移的前摇就去打断（够得着就打，否则用解；碰到就断，被无限挡住也一样）；抓长后摇；被连打到轻拳不再硬直时想办法脱身；**没开展延时被贴身就拉开距离**（他的拳打得到我、我的拳打不到他），被逼到墙边有七成概率**从五条悟头上跳过去**；世界斩只在估计五条悟来不及打断时才念（按看到过的招推算他的冷却）；第二次反转术式留到更低的血线。 |
| 万（疯狂） | 再快一些；必定在墙边跳越；开着展延停在他拳头边缘（110–145）等一下，骗他先闪避或先出招；看到他闪避，等无敌过了、在闪避冷却好之前追一拳；展延开着却一直够不着就关掉改用解。 |
| 史上最强（噩梦） | 再快一些，被打断或被控之后几乎不迟疑；没开展延被贴身一定拉开；读习惯：记下最近 16 次“展延贴近”时五条悟的第一反应（闪避、出招、跳、退、不动），某种反应占七成以上就针对着改节奏（习惯闪避或抢招就一定先停下来骗，习惯不动就直接压上去）。 |

所有新行为每个机会只抽一次签、只排一次反应时间（不会每 tick 重抽），只看画面上看得到的东西（五条悟的动作、念咒、飞行物、他用过哪些招），不读玩家的按键。

## v0.8：十种影法术与原身

能用什么由 `BattleConfig.sukunaDifficulty(难度)` 决定（三轮只有顎吐；里梅以上还有解、世界斩、法阵、魔虚罗、原身）。新加的决策（`SukunaAi.wantsTransform / wantsSummon / poke`，参数在 `AiTuning`）：

| 参数 | 三轮 | 里梅 | 万 | 史上最强 |
|---|---|---|---|---|
| 顎吐牵制的概率（每个合适的机会） | 40% | 30% | 25% | 20% |
| 最早召唤魔虚罗（有效战斗时间） | — | 3 秒 | 2 秒 | 1 秒 |
| 召唤时离五条悟至少 | — | 300 | 280 | 260 |
| 变原身血线（魔虚罗不在场） | — | 35% | 30% | 25% |
| 魔虚罗在场时的紧急血线 / 最多再等 | — | 20% / 3 秒 | 18% / 4 秒 | 15% / 5 秒 |

- 优先级：变原身 → 处理飞来的招 → 召唤魔虚罗 → 打断、抓破绽 → 平常的打法。
- 召唤：没有来招、他手上没在起招、赫打不过来（看到过他用赫就按冷却推算）才念；冲过来、瞬移、苍、茈留给玩家打断。
- 顎吐：中距离（180–560）牵制，魔虚罗在场时不牵制；打断念咒时只在“剩下的念咒时间 > 手影 + 俯冲”时才放。三轮没有解：顎吐冷却时就去贴身开展延。
- 魔虚罗自己的 AI 各难度一样、没有随机：每 0.1 秒想一次，够得着（120）出拳，再远一点（210）挥剑，否则往五条悟那边走；显现、被控、宿傩开展延时不动。

模拟结果和对照实验见 `notes/宿傩平衡.md` 的 v0.8 一节：里梅以上的胜率由用户定的 ×1.1 和“原身回满血”决定，AI 没有为了凑胜率往回调。

## 附：Astra 的方案（原文）

建议采用 **“三轮保留原 AI，后三档使用同一套事件驱动战术状态机，逐档开放行为”**。四档都维持宿傩 **10800 血、原伤害和原技能时间**，不加领域展开，不加霸体或隐藏闪避。

以下是可实现的首轮参数和规则，**不是已跑出的平衡结果**。本次只读查看，没有修改文件或运行会生成文件的构建。

先说明两个核对结果：

- 当前 [Tuning.java](core/src/main/java/com/shinjuku/showdown/core/Tuning.java) 和 `World.java` 仍是旧反转术式：每次回复 450、受击或受控打断。下文按你指定的新规则设计：**170/秒，治疗 180 tick，共 255，一局最多 510，不可打断**。
- [上一轮记录](notes/宿傩平衡.md:42) 的实测五条胜率是 **基础 5%、标准 59%、熟练 59%**。熟练脚本没有明显强于标准，因此不能直接把它当成“高手玩家”。

**一、四档的行为区别**

| 难度 | 核心表现 | 相比上一档新增 |
|---|---|---|
| 三轮／标准 | 直白地开展延追打，中距离用解推进适应 | 保留现有行为；只有简单试探，没有记忆 |
| 里梅／困难 | 会停一下、退一下，看到长破绽才行动 | 进退试探、单发解观察、识别三种念咒、瞬移前摇、较长后摇；按弹道选择躲法 |
| 万／疯狂 | 能主动诱导玩家交招，再利用其空当 | 展延压近后退、延迟出拳、闪避冷却追击、落地拦截、按剩余窗口选择打断；主动关闭展延 |
| 史上最强／噩梦 | 观察同一玩家的应对，改变下一次接近和出手节奏 | 有限窗口习惯统计、方向倾向、诱饵类型切换、对惯用反击预先布置位置 |

“聪明”的可读表现应当是：玩家能发现它为什么等、为什么退、为什么这一拳晚了，而不是所有招都被瞬间破解。

**三、先建立统一的观察和执行规则**

现有 [SukunaAi.java](core/src/main/java/com/shinjuku/showdown/core/SukunaAi.java) 是多个分支同时设置布尔意图。后三档应改成“观察事件 → 排队反应 → 单一计划 → 单次动作”。

允许读取或推导：

- 双方可见位置、朝向、空地状态、动作动画、念咒阶段。
- 已观察到的动作持续了多久。
- 可见飞行物的位置、运动方向、大小、场区。
- 宿傩自己的全部资源。
- 根据**实际看到的五条出招**推算冷却；没看清的按“未知”处理。

禁止读取：

- `TickInput`、输入缓冲、按住或松开标记、玩家下一招。
- 用 `redReleased`、`purpleReleased` 提前区分尚未显现的点按／长按。
- 直接读取五条冷却来做精确反制。
- 苍尚未显示的最终落点；飞行中只用可见轨迹估计，形成吸引场后才使用其可见中心和范围。

观察到普通起手，并不等于知道玩家会继续念咒。

```text
think():
    out.clear()
    aiClock++                         // 仅 think 实际运行时推进
    更新可见动作实例、弹道轨迹、习惯统计
    更新整数冷却

    if !sukunaCanAct():
        丢弃行动计划和一次性意图
        标记 wasLocked
        return

    if wasLocked:
        设置 recoverDelay
        丢弃此前失效的破绽事件

    if recoverDelay > 0:
        return

    if 自身不是 FREE 或 sStagger > 0:
        允许观察，不发行动意图
        return

    将新事件入队：
        eventKey = 类型 + 可见实例序号
        readyAt = 首次观察时刻 + 一次抽取的 reactDelay
        accepted = 一次抽取的行为概率
        对威胁另抽一次 mistake、dodge
        不得因重复观察刷新 readyAt 或重新抽签

    从已到反应时间且仍有效的候选中选择一个计划
    复核距离、高差、冷却、剩余窗口、当前威胁
    输出最多一个动作脉冲，以及该计划允许的移动
```

优先级建议：

```text
即将命中的威胁防守／能及时消除威胁的打断
> 瞬移、念咒等时限打断
> 可命中的破绽反击
> 连打脱身
> 已提交的试探或诱招
> 治疗／世界斩／展延资源计划
> 常规接近与解
```

反应延迟从第一次看见事件开始算，不能到决策 tick 才开始，再额外等一轮。反应结束后的计划执行也不再等 `decideInterval`。

对已发出的技能等待动作状态确认；被执行器拒绝时清掉该意图，不能下一 tick 自动重发。同一机会不重新抽签；机会过期或冷却结束后才可能产生下一次机会。

**四、试探和诱招的具体规则**

**1. 进退试探：里梅开始**

触发：双方没有明显攻击威胁，距离 150–240，试探冷却结束。

```text
抽 probeChance 一次：
    前进最多 18 tick，距离到 115 即停止
    不出拳，后退最多 24 tick，距离到 180 即停止
    观察到本次计划开始后 48/60 tick 为止

若五条开始攻击、闪避或念咒：
    创建对应反应事件
    按正常反应延迟处理
若没有回应：
    回到常规接近或中距离模式
```

这是移动试探，没有无成本取消技能。墙边无法后退时，不启动这个计划。

**2. 用解点一下：里梅开始**

触发：未开展延、`ampLock==0`、解和公共攻击间隔可用、距离 240–520、高差≤70，没有更紧急事件。

```text
采用试探计划后，只发一发解
正常承担 2 tick 起手和 18 tick 收招
观察玩家是否前压、退走、闪避、跳跃、反击、无反应
这段观察时间不自动补第二发解
```

解主要用于打断和适应，不能把“无限挡住后玩家掉血”作为收益。

万和噩梦额外判断：若距上次可见法阵转动不足 120 tick，且没有打断目标，则降低继续发解的优先级。四格已满但尚未到 12 秒时，不为不存在的额外适应收益刷解。

**3. “假装开展延”：万开始**

当前没有“展延起手可取消”的机制，因此拆成两种合法表现：

- **假接近**：进入通常开展延的位置，停顿，再退开；根本不发 `amp`。
- **真开假打**：真的完成 18 tick 展延起手，靠近至 110–145，等 12–24/30 tick，不立刻出拳，再观察回应。

第二种会消耗展延持续时间。不能假播展延特效，也不能撤销已经开始的 `S_AMP_START`。

```text
展延有效 && 距离 110..145 && ampBaitCd==0：
    抽 ampBaitChance
    暂缓出拳 baitWait tick

    看见闪避：
        记录方向和开始时刻
        转入“闪避后追击”事件
    看见出招：
        能安全退出攻击范围则后退
        等可见后摇形成后再申请反击
    无反应：
        最多等待一次，然后正常压近
```

不会对空白等待每 tick 重新抽“再骗一下”。

**五、抓破绽：看什么、来不来得及、用什么**

统一采用窗口检验：

```text
反应完成后：
    earliestContact =
        自身必要等待 + 接近耗时 + 动作实际首次接触耗时

    若 earliestContact + WINDOW_MARGIN >= 对方保证无法脱离的剩余时间：
        不标记为“确定惩罚”
```

当前体术首个有效 tick 是起手之后，保守按 **9 tick**；解按 **3 tick** 预算。接近耗时只能对固定位置或明确轨迹估计，不能假定自由状态玩家会站住。

| 可见事件 | 可利用窗口 | 里梅 | 万／史上最强 |
|---|---|---|---|
| `BLUE_CHANT / RED_CHANT / PURPLE_CHANT` | 当前咏唱剩余时间 | 反应后用解打断；展延贴身可体术 | 比较关展延用解与贴身体术哪个更快 |
| `TP_WINDUP` | 总共 24 tick | 仅反应较快、解已就绪时可能打断 | 优先解；展延中仅近身且时间够才体术 |
| `FIST_WINDUP` | 总共 14 tick | 通常来不及，转防守 | 也不保证打断；主要惩罚后摇或预先站位 |
| `FIST_RECOVER` | 26 tick，当前无移动取消 | 若展延已开且及时进入窗口，体术 | 更常抓住；过期则不追发 |
| `MELEE_RECOVER` | 最早第 4 tick 可取消 | 不当成稳定长破绽 | 观察到空挥后推进；不凭完整 10 tick 后摇作保证 |
| `RED_RECOVER / PURPLE_RECOVER` | 按对应最早取消时点算 | 通常只争位置 | 必须同时排除已发出的赫／茈威胁 |
| `BLUE_RECOVER` | 只有 6 tick | 不主动追求反应惩罚 | 不虚构可抓的长后摇 |
| 正在下降，即将落地 | 没有普通落地硬直 | 不专门处理 | 预先移到落点附近，满足高度和时间才拦截 |
| 已观察到 `DODGE` | 无敌 18 tick，冷却 60 tick | 不专门追击 | 无敌结束后、预计冷却结束前尝试体术 |

这里有三个重要限制：

1. **苍拳不能靠噩梦 12–18 tick 反应稳定打断。**  
   12 tick 反应再加解的接触时间，已经超过 14 tick。高难度针对它应靠诱出空挥、站位和后摇反击；不能偷偷把专项反应改成 0。

2. **未开展延的体术、解碰到普通后摇，并不能穿无限造成伤害。**  
   没开展延时，普通后摇主要用于接近、开罩、推进适应；打断脆弱前摇是另一回事。

3. **闪避冷却中仍能跳、走、攻击和用其他合法防御。**  
   冷却仅增加进攻价值，不等于必中窗口。

闪避追击的具体规则：

```text
记录 observedDodgeStart 和实际可见移动方向
reactionReady 后：
    若仍在无敌期，等待或调整位置，不挥空拳
    预计接触时刻必须 >= start+18
    且 < start+60
    且体术届时可触及、展延仍有效
    才发一次 melee

追不上则结束追击；不能盯着不存在的冷却优势冲到场边
```

落地拦截只预测普通跳跃或已知的固定轨迹。若五条进入苍拳、瞬移或改变轨迹，原预测失效。普通落地可以立即行动，因此这是有风险的压落点，不是保证命中。

**六、防守与连打脱身**

后三档对每个新威胁先经过 `reactMin–reactMax`，成功采用防守的概率为：

```text
(1 - mistake) × dodge
```

每个威胁只抽一次。之后可以按 `defenseReplanGap` 重评路线，不重新抽成功率，不跳过首次反应时间。

候选行动固定为：

```text
原地、左走、右走、原地跳、左跳、右跳
```

用当前可见弹道和自身物理，预测未来 `defenseHorizon` 内的碰撞；优先选择不碰撞、远离苍场、不会把自己送进墙角的路线。相同评分按固定顺序打破平局。

- **赫**：能离开射程末端就退出，否则判断跳起后的身体是否真的避开弹体。普通赫速度很快，近距离看见弹体才反应，允许躲不过。
- **普通茈／200% 茈弹体**：优先可行的跳越；大茈半径更大，不能复用普通茈的跳跃时机。横向后退通常只是延迟碰撞，不能算成功躲避。
- **苍飞行阶段**：根据可见轨迹远离可能形成的吸引区；已经形成 `PULL` 后避开真实场区。已经被吸住则无行动输出。
- **无指向茈**：沿能最快离开扩张范围的路线移动；已无可行路线就接受命中，不制造无敌能力。
- **200% 茈念咒**：能赶上就解打断；不能赶上则提前规划闪躲弹体，不能一直追到发射前仍在地上。
- **瞬移前摇**：能及时接触就打断。当前瞬移会定位到宿傩背后并进入固定动作，**前摇结束后的普通跳退不能当作可靠躲法**；失败就正常承受连段。

展延中打断念咒：

```text
meleeETA = 接近耗时 + 9
offThenDismantleETA = 关闭动作调度 + 12 tick ampLock + 解接触耗时

若 meleeETA 满足窗口且更快：
    贴近体术
否则若 tacticLevel>=2 且 offThenDismantleETA 满足窗口：
    发一次 ampOff
    等实际 ampLock==0，再复核事件，发一次解
否则：
    防守预备
```

不能同 tick 同时发 `ampOff` 和解。

连打脱身：

```text
被连打期间：
    观察并计数实际可见受击
    不能行动时输出全空

恢复合法行动 + recoverDelay 结束后：
    每 escapeCd 最多申请一次脱身计划
    抽 escapeChance

    已开展延且体术能及时接触：
        反击
    未开展延且已确认本轮连续轻拳进入不再硬直阶段：
        若没有赫、苍拳、瞬移等新威胁，可尝试开展延
    否则：
        选择可行的后退或跳退
```

“三下后轻拳不再硬直”只是现有连段衰减，不保护它免受其他招式，也不允许在 `sukunaCanAct()==false` 时偷开罩。

**七、噩梦的习惯学习**

用固定数组和环形缓冲，不做机器学习，不跨局保存，不读取玩家输入。

每种情境保留最近 16 次有效观察：

```text
情境：
    展延接近
    解试探
    展延出拳

回应：
    左闪、右闪、出招、后退、跳跃、无回应
```

另保存闪避相对方向：向宿傩内侧／向外侧，避免换边后误用绝对方向。

规则：

```text
一次试探或进攻只开启一个观察窗口
同一段玩家动作只能归入一个窗口
记录窗口内第一个可见的主动回应
受控导致无法回应的样本丢弃
有效但没有回应的窗口记为“无回应”

N >= 6 且 bestCount*100 >= N*70：
    建立该情境的习惯标签

每次新计划：
    65% 采用针对策略
    35% 维持普通策略
```

针对策略：

| 观察到的习惯 | 下一次改变 |
|---|---|
| 展延一接近就闪避 | 在 110–145 停顿，先让对方闪；看见实际闪避后再追 |
| 总向同一侧／向外闪 | 接近前调整站位，保留追击路线；不提前攻击尚未发生的闪避 |
| 看到展延出拳才闪 | 不假定移动试探能骗到；混合正常出拳和延迟节奏，实际闪避后再判断追击 |
| 展延贴近就放苍／赫 | 保持在其常用出手边缘，诱出后避让，再进入真实空当 |
| 解之后总前冲 | 下一次少用解，预留展延接近计划 |
| 几乎不回应试探 | 降低空等，恢复直接压迫 |

**习惯只改变事前策略，不减掉反应延迟，也不提供未来位置。** 玩家改变打法后，旧样本会随着 16 次滑动窗口自然消失。

**八、资源管理**

**领域展延**

里梅开始，开展延前检查：

```text
自身落地、技能可用
18 tick 起手期间没有已知必中的威胁
开启后仍有足够时间接近并打出至少一拳
```

万和噩梦额外：

- 对方连续远离，超过 `ampExitFarTicks` 仍无法进入体术范围：关闭展延，恢复解和适应路线。
- 有长咏唱可打断，关闭后用解明显更快：按上面的分阶段计划关闭。
- 展延剩余时间不够支撑接近＋体术首次接触：不再无意义追拳。
- 不能以反复开关规避 12 tick 术式锁和关闭后 240 tick 冷却。

**世界斩**

第一次和后续必须分别评估。当前第一次起手就消耗束缚机会，打断不退；后续则有 144 tick 咏唱。

```text
候选条件：
    已解锁、冷却结束、落地、未展延、ampLock==0
    在设定距离内
    无已知弹体会在起手期间命中
    五条没有正在进行、能及时打断自己的可见动作

估计五条“若立刻采取行动，最快何时能打断”
未知资源按可用处理
若这个时间 <= 世界斩起手 + worldSafetyMargin：
    拒绝本次机会

否则每个合格机会只抽一次 worldChance
未采用则至少等 worldRecheckGap
```

估计应考虑瞬移前摇、赫／茈前摇与飞行时间，不能只算跑过来打拳。

使用倾向：

- 首次 48 tick：优先真正安全的中距离；确认方向稳定，不为了抢第一次而近身白送。
- 后续 144 tick：优先已观察到关键远程和瞬移刚消耗、且足够远的时机。
- 五条普通后摇普遍远短于 144 tick，不能把后续世界斩当通用后摇惩罚。
- **骗掉一次闪避不足以保证世界斩命中**：对方仍能跳，而且闪避冷却比咏唱短。

严格筛选可能让高难度世界斩次数减少，这是合理结果。对当前会精准跳预警的脚本，不应为提高命中率偷偷缩短预警或改变锁定规则。

**反转术式**

新规则每次最多回 **255**，起手＋治疗＋收招共 **240 tick＝2 秒**。

```text
剩余次数>0、冷却结束、未展延、ampLock==0、落地
缺血 >= 255
血线满足本次使用阈值
每 rctRecheckGap 最多重新考虑一次
```

新 AI 还应检查：

- 没有正在命中的高伤害弹体或瞬移前摇。
- 当前可见攻击和最早接近时间估计，治疗期间是否可能吃到超过收益的伤害。
- 万和噩梦可在低于旧距离门槛时治疗，但必须有已观察到的资源空当；不能因“不可打断”就迎着 1700 伤害茈回血。

“不可打断”建议落实为**治疗流程独立于受击动作**：受击、被吸、领域不会取消已经合法启动的治疗；但仍正常扣血、击退和受控，KO 停止治疗。领域中不得新开治疗，也不能借治疗恢复行动权。这样才不会把“不可打断治疗”误做成霸体。

**九、BalanceSim 胜率目标与调参顺序**

先保持 [GojoBot.java](core/src/test/java/com/shinjuku/showdown/core/GojoBot.java) 三套策略不变。下表是采用新反转规则后的首轮验收目标，全部指**五条胜率**：

| 五条脚本 | 三轮 | 里梅 | 万 | 史上最强 |
|---|---:|---:|---:|---:|
| 基础 | 3–10% | 2–8% | 0–5% | 0–4% |
| 标准 | 55–65% | 40–50% | 25–35% | 12–22% |
| 熟练 | 55–70% | 42–57% | 28–43% | 15–30% |

基础脚本本来已经只有约 5%，没有足够空间体现四档差距，不值得围绕它强行拉开百分比。标准和熟练才是主要比较轴；也不强求每个种子下更高难度都赢。

用现有 [BalanceSim.java](core/src/test/java/com/shinjuku/showdown/core/BalanceSim.java) 的 `report(..., tweak)` 接入四套配置，未来验证时：

- 调参集：种子 0–999，四难度×三脚本，共 12000 局。
- 留出集：1000–1999，冻结参数后再验证。
- 90 秒有效时间、首次 KO 停止；超时单独统计，不从胜率分母删除。
- 每档超时目标低于 5%。
- 统计置信区间；1000 局时，50% 附近约有 ±3 个百分点抽样误差。

新增关键指标：

```text
瞬移前摇：可打断机会数 / 尝试数 / 成功数
念咒：可打断机会数 / 成功数
试探：次数 / 实际诱出动作数 / 后续有效命中数
体术：打在闪避无敌期的次数
防守：有可行路线的机会数 / 实际成功数
展延：开启次数 / 零有效命中次数
世界斩：机会拒绝原因 / 起手 / 打断 / 斩出 / 命中
治疗：实际总治疗量 / 治疗期间承受伤害
```

现有脚本不能验收全部行为：它们不会覆盖丰富的试探回应、苍拳、习惯改变；领域内念 200% 茈时宿傩没有行动权，也不能拿它检验打断能力。另加固定输入场景验证这些行为，**不修改三套脚本来美化胜率**。

调参按以下顺序：

| 偏差 | 优先调整 |
|---|---|
| 高难度反而更弱 | 先查试探空等、追闪避是否追不上、是否过度关展延；降低 `probeChance/ampBaitChance` |
| 五条胜率过高 | 先提高合法破绽利用率、减少无效世界斩，再调 `punishChance/interruptChance` 和接近策略 |
| 五条胜率过低 | 先降低瞬移打断率和抓破绽率，再增加失误；最后才延长一般反应 |
| 基础几乎全败、标准合适 | 接受脚本能力下限，不动血攻补偿 |
| 噩梦读习惯收益过大 | 降低 `learnExploitChance`，提高最少样本数 |
| 超时或长时间拉扯 | 缩短空等和拉距离计划，增加正常进攻机会；不先增加伤害 |

**十、接入风险与验证重点**

1. **不能只改参数。**  
   旧结构缺少事件去重、单一计划、习惯状态和 `ampOff` 输出。建议保留三轮旧路径，新建战术路径，共用技能执行器。

2. **现有多个意图会互相覆盖。**  
   `World` 实际按关闭展延、体术、解、开展延、世界斩、治疗的顺序接收。新 AI 应先选唯一动作，不能设置多个布尔值后指望执行器理解战术优先级。

3. **旧概率会迅速趋近必选。**  
   “每 6 tick 有 65% 概率用世界斩”连续评估五次，至少选中的概率已超过 99%。新概率必须按事件／机会抽一次。

4. **旧计时有不同单位。**  
   `modeTimer` 按决策次数递减，修改 `decideInterval` 会同时改变换打法频率；新模式时间统一为有效 tick。命中停顿期间 `World.tick` 仍增加，AI 倒计时应跟随实际逻辑推进，不能混用。

5. **观察不能被自身出招阻断。**  
   旧 AI 在自身非 `FREE` 时提前返回，会错过飞行物和对手动作开端。新结构先观察后判断能否行动；动作执行中只能积累信息，不能取消自己的收招。

6. **威胁不能只取第一个。**  
   旧 `threatId()` 按固定顺序返回一个威胁。新 AI 应同时评估赫、茈、苍、无指向茈，按预计碰撞时间选择；否则躲赫时可能跳进苍。

7. **性能可以严格有界。**  
   六条候选路线、最多四类场景威胁、最长 90 tick 预测，每 6–12 tick 重评即可；固定数组，无每 tick 对象分配，不复制完整 `World` 搜索未来输入。

8. **确定性不仅是种子。**  
   固定候选顺序、平分裁决、抽签次数和事件序号；所有计时与计数用整数。位置预测复用当前物理，若量化采用固定规则。AI 继续使用独立 RNG，不影响黑闪 RNG。

9. **新治疗要同步更新统计。**  
   170000 毫血/秒不能用单个整数每 tick 治疗值精确表达，应使用整数余数累计。治疗期间同时受伤时，现有“正 HP 差”统计会漏算治疗，需累计实际治疗事件或独立计数器。

10. **验收规则边界。**  
    固定输入回放必须复现；不同隐藏输入但相同可见观察应产生相同 AI 意图；受控时输出全空；前摇打断要测窗口边界；普通解始终不能伤害无限；已经提交的世界斩和展延不得免费取消。
## v0.11：恐惧和空间斩（Astra 的方案）

用户的要求：宿傩有恐惧值，受击前预估一段时间内可能受到的伤害，实际低于预期恐惧降低、高于预期恐惧增加；恐惧越高越不想用技能、攒技能，恐惧高会连连后退；新增空间斩，恐惧偏低、打了 20 秒以上、血量 25% 以下时 AI 能放，斩中秒杀、斩不中力竭，想放时看到代价会涨恐惧，越怕越不愿意。

实现时和方案不一样的地方：
- 贴身体术的预估：方案给的是 190 / 76 / 19（110 / 220 / 420 以内），模拟里实际贴身一秒挨 450 左右，按实测校准成 420 / 160 / 40；不然估得总是偏低，恐惧只涨不跌（校准前平均 50–75，四成时间在 60 以上）。
- 空间斩不查 fastestInterrupt（五条悟只要可能有瞬移就会判“来得及打断”，几乎放不出来），只要 260–850 的距离、他手上没在起招、没有招飞过来；这本来就是赌命的一刀。
- 使用率按恐惧线性打折（0.55 / 0.65 / 0.75 ×（1 − 恐惧 / 30）），方案是平方，恐惧 20 时只剩 1.5%。
- 观察（记五条悟用过什么招）三轮也跑，但三轮不登记战术机会；预估里用到的“可能会用的招”四个难度都按看到的推算。
- 没有做的统计：预测按来源分组、后撤的位移和撞墙、玩家应对的成功原因（BalanceSim 只统计了恐惧分布和空间斩的流程）。

### 方案原文

建议采用你理解的**“预测伤害—实际伤害误差”模型**。恐惧高时，宿傩减少主动交技能、连续后撤；但保留必要的打断和脱身，否则会退化成被追着打的木桩。空间斩作为独立的一次性绝境技能，保留现有世界斩。

已读指定代码和文档，没有改文件。以下数值是**可直接实现的首版参数，尚未模拟验证**。旧 AI 文档中“各档血攻相同”等历史描述，以当前 `BattleConfig` 和 v0.10 为准。

**1. 恐惧模型**

**基本参数**

| 项目 | 建议 |
|---|---|
| 恐惧值 `F` | 0～100；内部整数保存百分之一点，即 0～10000 |
| 初始值 | 四档统一 20，不让高难度天生没有恐惧 |
| 预测窗口 | 120 个有效 tick＝1 秒，不重叠 |
| 预测时点 | 窗口开始，冻结本窗口期望伤害 `E` |
| 实际伤害 `A` | 窗口末 `damageTaken[SUKUNA] - windowDamageStart` |
| 更新频率 | 每窗口一次；受控、出招中也结算 |
| 单位 | 伤害内部继续用毫血，下面表格用普通血量 |
| 时间 | `fightTicks`；命中停顿、过场不推进窗口 |

预测器只读取可见动作、位置、速度、弹体、领域、法阵等，不直接读五条悟实际冷却，更不读输入、黑闪伪随机状态。

当前 `observe()` 只对里梅以上运行。应拆出**四档共用的观察记录**，战术机会登记仍按难度开启。记录实际看见的普通／强化版本，避免把所有赫都按 480 tick、所有茈都按 1800 tick 推算。

**期望伤害的计算**

采用：

```text
E = 已经发生的动作／弹体预计造成的伤害
  + 尚未起手、但资源可能可用的潜在伤害
```

所有项只计算**未来 120 tick 内预计落到宿傩身上的部分**。相同招式从念咒变成弹体不能计算两遍；瞬移连段不能同时再加其对应普通术式伤害。

下表给出首版权重。

| 看什么 | 本窗口期望贡献 |
|---|---|
| 五条悟近身，能继续体术 | 单次平均伤害 `50×85%+350×15%=95`；距离≤110：预计 2 次接触，190；110～220：0.8 次，76；220～420：0.2 次，19；更远为0 |
| 已看见体术起手 | 用本次预计命中率×95，替换上面的一个预计接触，不额外叠加 |
| 已看见苍拳／下砸苍拳 | 平均伤害分别161.5／218.5，再乘命中率；不偷看此次是否黑闪 |
| 普通赫可能可用 | 射程409.6以内、五条面对宿傩且能在窗口内行动：`150×0.20=30` |
| 普通茈可能可用 | 同向、距离150～960、能在窗口内完成前摇及飞行：`850×0.10=85` |
| 苍可能可用 | 距离≤614.4、能在窗口内落地：预计占据吸引场0.5秒、平均出力50%，再乘20%使用率，贡献5 |
| 瞬移可能可用 | 只选一个候选：普通瞬移苍／赫按较大可达伤害×10%；未看见念咒时，不额外假设会用瞬移·茈 |
| 已看见赫／茈念咒或前摇 | 按实际版本伤害×预计命中率×完成概率；完成概率通常0.6，被领域控制的宿傩无法打断时0.95 |
| 飞来的赫／茈 | 用弹体实际公开版本：150／550、850／1700，再乘命中率 |
| 无指向茈正在扩张 | 850×预计命中率；已命中过宿傩的实例不再计入 |
| 苍已经落地或正在飞向落点 | 按下面的持续伤害公式，最多算剩余寿命和本窗口重叠部分 |
| 可见瞬移固定连段 | 苍按窗口内剩余命中次数×115；赫550；瞬移·茈1900；已经锁入固定动作时命中率1 |
| 茈·最大输出的可见咏唱 | 能在窗口内完成咏唱则按3500×完成概率；不能完成则本窗口不加3500 |
| 无量空处 | **自身不加伤害**；只改变躲避／打断能力与上述命中率 |
| 魔虚罗 | 不把它受伤加入宿傩预测；它也不是替宿傩挡茈的可靠掩体 |

苍的伤害必须沿用当前平方衰减：

```text
q = clamp((radius - distance) / (radius - BLUE_CORE), 0, 1)
E_blue = 100 × q² × 本窗口预计仍在场内的秒数
```

已被捕获时 `q=1`；场内尚未捕获时，首版按当前位置计算，另把受控带来的弹体命中率提高。不要把“最大输出苍”误写成200 DPS：现有实现提升的是范围和吸力。

命中率统一定义，便于实现和调参：

- 预测轨迹不与宿傩身体相交：0。
- 会相交，但存在合法走开／跳开的路线：0.45。
- 当前路线会相交，经过本难度反应时间后已经来不及避开：0.85。
- 被领域、捕获或固定连段限制，无法避开：1。

位置预测用当前速度和已知物理；不预测玩家未来按键。最多检查原地、左右走、原地跳、左右跳六条路线。预测器本身无需抽随机数。

“技能可能可用”按看见的使用时间推算，未知视为可能可用，但仍只乘上表的小概率。为了不把互斥操作堆成虚假的巨额伤害：

- 未起手术式候选只取期望最大的两项，按“最大项＋第二项×0.5”计算。
- 五条已在长咏唱／固定动作中，取消普通体术和其他术式的潜在项。
- 已存在同种弹体／连段时，不再添加它的“可能使用”项。
- `E` 不按剩余血量裁剪；死亡后的最终窗口只作统计，不再影响行为。

这些190、85、30是**估计损失**，不是修改招式伤害。

**误差更新**

令 `e=A-E`，设置15血误差死区：

```text
e > 15：
    ΔF = min(24, kUp × (e-15)/100)

e < -15：
    ΔF = -min(12, kDown × (-e-15)/100)

否则：
    ΔF = 0
```

| 难度 | `kUp`：多挨100血 | `kDown`：少挨100血 | 安全时自然回落／秒 |
|---|---:|---:|---:|
| 三轮 | +4.0 | -2.0 | 0.5 |
| 里梅 | +3.6 | -2.4 | 0.7 |
| 万 | +3.2 | -2.8 | 0.9 |
| 史上最强 | +2.8 | -3.2 | 1.1 |

自然回落只在本窗口 `A=0、E≤50` 时发生，降至初始值20为止；预测误差本身仍能把恐惧降至0。最终统一 `clamp(0,100)`。

例如里梅预测200、实际500，恐惧约涨10.3；预测500、实际200，约降6.8。一次完全意外的3500伤害最多涨24，避免立即顶满。

**特殊情况**

- **魔虚罗受伤／死亡：不计入。** 它影响局势，但不是宿傩本人损失；首版不额外增加“失去式神恐惧”。
- **反转术式：回血不抵消受伤。** 一秒挨300、回170，实际受伤仍是300。
- **原身回满：不算负伤害、不清空恐惧、不清空窗口。** 原身能活下来，不代表之前没有受到惊吓。
- **演出中的伤害：必须计入。** 当前固定演出可能暂停 `fightTicks` 却调用 `apply()`；保留窗口起点累计值，下一次正常结算即可包含这些伤害。
- 若窗口开始已处于确定的固定演出，其尚未结算伤害计入当前窗口；若演出在窗口中途突然成立，未提前预测到的部分就是本窗口的正误差。不能受击后回头修改 `E`。
- 结算放在独立观察／统计入口，不放在 `sukunaCanAct()`、`FREE` 等提前返回后面。战斗结束时补记最后一个未满窗口，仅用于统计。

这里存在一个符合模型的现象：**预料到会挨大招，真的挨到了，不一定增加恐惧。** 如果将来希望“预知危险也害怕”，应另加危险感知变量，不能偷偷混进预测误差。

**2. 恐惧如何落到现有 AI**

令 `f=F/100`。先选行动计划，再发唯一技能意图；不要在 `emit()` 阶段逐个布尔值重抽签。

“攒技能”的定义是：**延迟使用已就绪技能，把有限次数和冷却窗口留给更安全的机会。** 不增加充能次数，不冻结冷却，不延长已经开启的展延。

| 现有决策点 | 恐惧影响 |
|---|---|
| 常规 `attackChance` | 乘 `1-0.65f`；F=80时保留48%原概率 |
| `attackTimer` | 新间隔乘 `1+0.75f`，已排定的间隔不每tick改 |
| `approachWeight`／`approachWeightAdapting` | 乘 `1-0.70f` |
| 常规开展延 | 候选机会采用率 `1-0.70f`；拒绝后120tick再评，避免每次决策反复抽到必开 |
| 已开展延 | 不因恐惧立即关闭；取消“够不着就无条件前进”的覆盖，让恐惧后撤计划能执行 |
| 解试探／攒适应 | 原概率乘 `1-0.80f`；所有额外试探分支一起调整 |
| 顎吐牵制 `poke()` | 原概率乘 `1-0.85f`；拒绝顎吐后不能无条件改发解绕过节制 |
| 世界斩 `worldChance()` | 原概率乘 `(1-f)²`；保留安全筛选与120tick重评间隔 |
| 魔虚罗 `wantsSummon()` | 原条件成立后，以 `1-0.70f` 接受；拒绝后240tick再评；保留成功一局一次 |
| 反转术式 `wantsHeal()` | 保留原血线和至少缺255血；安全候选采用率 `1-0.35f`，240tick重评。恐惧高也会舍不得用，但不完全拒绝治疗 |
| 原身 `wantsTransform()` | 不受恐惧抑制，继续最高优先级 |
| 抓后摇／追闪避 | 原机会概率乘 `1-0.50f`；高恐惧减少追击，不取消已经合法开始的动作 |
| 普通念咒打断 | 原机会概率乘 `1-0.25f` |
| 高伤害茈、瞬移·茈打断 | 保留原概率：及时打断是自保；仍需真实反应时间和接触时间检验 |
| 连打脱身 | `escapeChance` 提高到 `base+(1-base)×0.5f`；优先现成展延反击、合法越墙，其次后退 |
| 进退试探 | 启动概率乘 `1-0.60f`；前进段缩短为原时长×`1-0.5f` |
| 展延骗招／习惯学习 | 保留观察；恐惧后撤时暂停骗招计划，不让 `baitTimer` 把撤退覆盖成站着不动 |
| 躲飞行物 | 保留反应延迟；防守采用率适度提高 `dodge+(1-dodge)×0.3f`，不新增无敌能力 |

所有机会类概率在**登记机会时**计算一次，失败后不得在同一机会逐tick重抽。

**距离管理**

在非紧急状态下，对现有 `lo/hi` 做修正：

- 中距离、准备开展延：`lo += 120f，hi += 160f`。
- 已开展延且F<60：`lo += 20f，hi += 35f`。
- 想回血：继续使用现有 `rctDistance`，不再叠加距离，否则可能永远走不到。
- 世界斩待机：只在本轮确实愿意使用世界斩时采用其距离分支。不能“怕得不敢放，却一直按准备世界斩的距离走”。
- `lo/hi` 保证有序，并裁到可实现的场地距离。

**“连连后退”做成明确计划**

- `F≥60` 进入惊惧状态，`F≤45` 退出，避免阈值附近抖动。
- 每段后撤24～36tick，即正常走动约66～99单位。
- 段间停顿6～12tick；一组连续2～3段，最多退约200～300单位。
- 距离达到目标便提前结束：

```text
targetDistance = min(620, 360 + 5×(F-60))
```

- 每组结束必须留60tick给普通防守／反击决策，再允许下一组。
- 恐惧到70／85时，下一组采用2／3段；段数和停顿只用 AI 自己的 RNG。
- 贴近危险、领域控制、实际受击可以中断移动计划；不会取消已开始的合法技能。

背后距可站立边界不足90单位时，停止申请向墙后退，沿用现有 `vaultChance`、起跳条件和跳跃冷却。三轮不凭恐惧凭空获得高级越墙能力；跳不过去就尝试现成展延反击或合法开展延。

**五条420、宿傩330，宿傩直线后退一定会被追上。** 因此距离<150且连续追击时，优先进入已有脱身分支，不连续刷新后撤计时。恐惧可以造成失误和被追打，但不能导致AI永久放弃反抗。

建议计划优先级为：

```text
原身
→ 紧急避险／来得及的高威胁打断
→ 连打脱身／墙边处理
→ 已提交的恐惧后撤
→ 空间斩机会
→ 召唤、治疗、世界斩
→ 普通战术和距离管理
```

高难度的优势主要是**预测更准确、误差后恢复更快、撤退更有办法**，而不是恐惧无效。

**3. 空间斩**

建议新增 `SPACE_SLASH`、`S_SPACE` 和独立力竭计时。它与现有世界斩共享部分表现／几何工具，但不复用世界斩的技能状态和次数。

| 项目 | 首版规则 |
|---|---|
| 难度 | 里梅、万、史上最强；三轮没有 |
| 配置 | 新增 `spaceSlash`，后三档启用，并要求 `shrine` |
| 恐惧硬门槛 | 起手时 `F<30`，严格小于 |
| 时间硬门槛 | `fightTicks≥2400`，即有效战斗20秒 |
| 血量硬门槛 | `0<hpMilli` 且 `hpMilli×4≤maxHpMilli` |
| 起手 | 120tick＝1秒，四档不随难度缩短 |
| 次数 | 一局最多起手一次；起手即消耗，被打断也不退 |
| 展延 | 开展延及 `ampLock>0` 时不能启动 |
| 领域 | 无量空处中不能启动；起手中被领域控制则中断 |
| 落地 | 必须在地面启动 |
| 世界斩关系 | 不消耗其首次束缚，不改其12秒冷却；空间斩不要求 `worldUnlocked` |
| 命中 | 绕过无限，正常接受闪避／瞬移无敌裁决；成功伤害结算直接清空五条当前血量 |

**为什么不要求学会世界斩？**

当前原身可能在12秒前出现，法阵随之消失，导致这一局根本学不会世界斩。空间斩如果再要求 `worldUnlocked`，会产生与玩家要求无关的隐性禁用。这里把空间斩定义为新的绝境能力，独立解锁。

**原身优先级**

保留现状：能变原身就先变。因而后三档通常在**原身第二条血降到25%后**才有空间斩机会；魔虚罗在场、尚未达到强制变身条件时，第一条血也可能获得机会。

不额外规定必须原身，也不为了空间斩压住原身回血。这一点需要在技能说明里明确。

**预警与判定**

建议采用前方水平斩带，保留跳跃这种玩家已经学会的应对：

- 起手立即出现独立的紫黑裂纹、明显音效和“空间斩”字样，不能只靠颜色区别于世界斩。
- 前60tick随五条的位置转向，显示虚线预览。
- 第60tick锁定**起点、方向、高度**，裂纹变实线，最后60tick完全不追踪。
- 第120tick进行一次判定，没有持续多帧扫人。
- 起点为锁定时宿傩前方20单位；长度960；高度离地50；半厚度10。
- 判定复用世界斩的身体矩形相交规则，但使用已保存的空间斩坐标。

应对方式：

- **闪避：可以。** 18tick无敌必须覆盖实际斩出时刻；看到预警立刻闪避通常过早。
- **跳跃：可以。** 五条脚底超过斩带上沿60单位即可避开。
- **瞬移：可以。** 前摇本身不无敌；成功进入固定动作或出现在锁定斩带背后才安全。
- **走开：可以。** 出射程或越过锁定起点背面；锁定后不追踪。
- **打断：可以。** 起手期任何实际受伤立即打断，包括不再造成硬直的第四拳，以及苍持续伤害。没有末段霸体。
- 斩出当tick仍先处理五条攻击，之后才处理 `spacePending`；已死亡／被打断就不出斩。

**“打不中力竭”**

定义为：**起手后没有完成有效致死伤害结算**，包括打断、空挥、闪避无敌、瞬移逃脱。不能用“几何相交了”冒充命中。

- 力竭360有效tick＝3秒。
- 不能主动移动、跳跃、攻击、展延、治疗或变原身。
- 立即关闭展延；不增加免伤，不增加额外受伤倍率。
- 挨打正常扣血、击退、受控；受击不清空、不重置力竭。
- 用独立 `spaceExhaustTicks` 保证换受击状态后仍然有效；动作动画可以是跪地或喘息。
- 时间到后仍有硬直、倒地、领域等控制，继续等待其结束。
- KO或战斗结束优先于力竭；命中即结局，不再产生力竭事件。
- 已在场式神继续按原规则行动，不额外删除。

3秒意味着明显惩罚，但不是无条件送掉剩余约1500～1800血。

**秒杀的实现**

不要直接写 `outcome=LOSE`，也不要塞一个巨大伤害常量。

建议给攻击增加明确的致死语义，或对 `SPACE_SLASH` 单独处理：

```text
apply()：
    先检查 invuln / present / outcome
    再经过 Defense 裁决
    若允许伤害且为空间斩：
        appliedDamage = target.hpMilli
        忽略 sukunaDamageMult
        累计 damageTaken，扣至0，发送正常伤害／命中事件
    后续仍由现有 KO / decide / endFight 路径分胜负
```

当前 `SPECIAL_BYPASS` 还依赖 `domains.specialBypass[source]`，而这个开关与世界斩解锁绑定。必须给合法空间斩单独增加防御裁决依据，**不能全局开启特殊穿透**，否则可能污染其他招式。

保持现有“同tick双方死亡算五条赢”的规则。空间斩结算前还要检查宿傩 `hpMilli>0`，因为扣成0到 `KO` 状态之间存在时序间隙。

**AI什么时候想放**

除了三个硬条件，还要求：

- 技能未使用、宿傩可行动且处于 `FREE`、没有力竭。
- 地面、未展延、无术式锁；公共攻击间隔结束。
- 五条活着；没有更高优先级的变身、打断或脱身计划。
- 距离260～850，五条身体接近地面，不正处于瞬移前摇／固定动作。
- 没有可见弹体预计在起手期间命中，没有苍场控制。
- 用观察到的资源推算 `fastestInterrupt`，要求超过“120＋本难度安全余量”。

这只是降低自杀式起手概率，**不判断必中**。五条仍然能看预警躲开。不因为观察到一次闪避，就认定120tick后仍在冷却——闪避冷却只有60tick。

**考虑代价与使用概率**

每360有效tick最多进行一次真正的空间斩考虑；必须先通过上述候选条件。未通过不加恐惧，也不抽签。

```text
F_before < 30

costFear = min(5, (30-F_before)/2)
F_after = F_before + costFear

pUse = baseChance × (1-F_after/30)²

baseChance：
    里梅 0.55
    万   0.65
    史上最强 0.75
```

固定点实现时令 `costFear` 不超过距门槛剩余量减一个最小单位，保证单次代价评估不会凭取整把自身直接顶到30。

例如：

| 考虑前恐惧 | 考虑后 | 里梅／万／史上最强使用率 |
|---:|---:|---:|
| 10 | 15 | 13.8%／16.3%／18.8% |
| 20 | 25 | 1.5%／1.8%／2.1% |
| 28 | 29 | 约0.06%／0.07%／0.08% |

这是**真正低恐惧时才敢赌命**的技能。若模拟发现过于罕见，先调基础概率或考虑间隔，不删预警、不加必中。

补充两个防死循环规则：

- 两次真实考虑间隔至少360tick，并且距上次考虑后至少完成一个误差结算窗口。
- F≥26时，下一次考虑要求恐惧相对上次考虑后至少下降2点，避免连续“想一下—害怕一点”无限逼近30。

第一次加的恐惧不退还；安全窗口和少受伤会逐渐让它收心。抽签后未采用不是起手，不消耗一局一次；执行器接受起手才消耗。起手后恐惧上升不自动撤招。

**4. GojoBot 与 BalanceSim**

**GojoBot需要新增应对，但不是看见就立刻闪避。**

- 基础脚本保持不主动识别空间斩，作为教学失败对照。
- 标准／熟练沿用24～36／12～18tick反应，按空间斩实例只抽一次。
- 标准以80%概率识别成功，熟练95%；失误率独立于最终是否能躲开。
- 反应完成后，若近身且能在斩出前接触，尝试打断。
- 否则优先定时跳跃；闪避作为替代，在预计斩出前6～10tick启动。
- 瞬移仅在对应资源可用、前摇及切入时间来得及时选择；不能视为零前摇逃生键。
- 不读取宿傩恐惧、未执行意图或本次随机结果，只读取可见起手、锁定预警和公开节奏。
- 新预警观察应放在 `maxHold/purpleHold/redHold` 提前返回之前；可以观察并决定松开可取消蓄力，但不能因此取消不可取消动作。

同时保留“未适配空间斩”的旧脚本开关，用于判断胜率变化到底来自技能还是脚本升级。

**BalanceSim新增统计**

| 类别 | 统计内容 |
|---|---|
| 恐惧分布 | 每局及全体按有效tick加权的均值、P50/P90；0～20、20～40、40～60、60～80、80～100占时 |
| 预测质量 | `E/A`均值、偏差、绝对误差；按近身／弹体／领域／演出分组 |
| 恐惧来源 | 伤害误差增减、自然回落、空间斩代价分别累计 |
| 后撤 | 组数、持续时间、位移、撞墙终止、后撤期间受伤、脱身成功 |
| 攒技能 | 就绪却因恐惧拒绝的次数与等待时间；各技能实际使用率 |
| 空间斩资格 | 满足三硬条件的局数及持续tick；原身前／后分别计 |
| 空间斩流程 | 候选、因安全拒绝、真实考虑、随机拒绝、意图、接受起手、打断、斩出、几何接触、实际致死 |
| 力竭 | 进入次数、原因、力竭期间受伤／死亡 |
| 玩家应对 | 看见、识别、尝试跳／闪／瞬移／打断、成功原因 |
| 胜负 | 以 `outcome` 为准，保留超时，避免空间斩另造一套胜负标准 |

事件应能区分 `SPACE_START / LOCK / FIRE / HIT / INTERRUPT / EXHAUST`。空间斩伤害从实际扣血统计，不能沿用现有某些事件中“标称伤害”的口径。

**5. 模拟验收目标**

以下都是**五条悟胜率**。你给的100/100、44/60、8/22、2/7，与v0.10标准／熟练的留出集结果一致。

这轮不改血攻和已有技能时间，不应强行恢复旧v0.7的目标。恐惧总体会削弱宿傩；空间斩只提供少量绝境逆转。

| 难度 | 现状标准／熟练 | 首版目标标准 | 首版目标熟练 |
|---|---:|---:|---:|
| 三轮 | 100%／100% | 98～100% | 98～100% |
| 里梅 | 44%／60% | 45～58% | 60～73% |
| 万 | 8%／22% | 10～20% | 25～38% |
| 史上最强 | 2%／7% | 3～9% | 9～18% |

三轮已经是教学档，增加恐惧不可能凭空让它更强，不应为追求表格好看补攻击或血量。

验收方式：

- 调参种子0～999；冻结后用1000～1999，并增加2000～2999作新留出集，因为原留出结果已参与本轮设计。
- 四难度×三脚本，每格至少1000局；90秒上限，超时保留在胜率分母中，目标<1%。
- 做“旧版／仅恐惧／恐惧＋空间斩”三组对照，另对空间斩应对开关做对照。
- 加空间斩后，相比“仅恐惧”，标准胜率下降以0～5个百分点、熟练0～3个百分点为首轮警戒线。
- 在**满足三硬条件且至少出现一次安全候选**的局里，空间斩起手占比先瞄准10～30%；不能要求所有低血局都放。
- 已起手空间斩对标准／熟练的致死率分别先瞄准5～20%／0～10%。即死招的主要价值包括逼回应和形成风险，不应靠高命中率保强度。
- 没有足够空间斩样本时，额外跑定制场景，不为凑统计放宽硬条件。
- 常规战斗恐惧长期处于80以上的占时若超过15%，优先查预测漏项和连退死循环。

这些目标是调参范围，不是对真人胜率的承诺。

**6. 实现风险与必须覆盖的边界**

1. **AI提前返回漏记伤害。** 观察和窗口结算必须独立于能否行动；固定演出暂停时不能重置伤害基线。

2. **窗口边界错位。** 明确“起点记录→经历120个有效tick→结算→下一预测”，不要把结算tick伤害计入两次。受击后不得修订已冻结预测。

3. **冷却与版本识别错误。** 普通／最大输出／瞬移茈的冷却不同；不能用当前简化的 `seenPurple` 推算所有版本，也不能读取实际冷却弥补观察缺陷。

4. **恐惧抑制被其他分支绕过。** `poke()`回退到解、额外解试探、强制 `approachMode=true`、展延无条件前追、战术分支提前返回，都需要统一仲裁。

5. **连续抽签变必放。** 所有新增概率绑定机会及冷却；不只修改 `attackChance` 数字。

6. **力竭被受击清掉或导致冻结。** 使用独立计时；不能让 `interruptSukuna()`换回 `FREE` 后恢复行动，也不能因 `sukunaCanAct()==false` 让力竭计时永远不走。

7. **死亡前多出一刀。** 空间斩最终结算检查血量、状态、胜负和pending；沿用同tick双倒判五条赢。

8. **无限与无敌混淆。** 空间斩破无限，但不破闪避／瞬移无敌；特殊穿透只授权这次合法攻击。

9. **“命中”统计虚高。** 几何相交、`apply()`允许伤害、实际致死分别统计；被无敌挡掉必须进入力竭。

10. **视觉预警和判定不同步。** 锁定起点与高度必须存快照，渲染与判定读同一份数据；不能显示固定裂纹、实际仍跟踪五条。

11. **原身导致技能几乎不可见。** 这是现有优先级的结果，应统计原身后低血资格及存活时长；不能偷偷降低20秒门槛补出现率。

12. **随机数和性能。** 新预测不使用战斗伤害 RNG；后撤、机会选择使用AI RNG。固定候选顺序、固定点恐惧、固定数组，避免每tick分配对象。相同种子和输入应严格复现。

实现顺序建议是：**先接恐惧观察与统计，验证预测口径；再接行为抑制和后撤；最后接空间斩、Bot应对和模拟对照。** 每一步都能独立判断偏差来自哪里。
