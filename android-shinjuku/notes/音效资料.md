# A. 术式听感与可直接合成的方向

先给这套游戏的**共同声音语法**：咒力感用窄带低鸣、带金属感的中高频谐波和短噪声起音；术式类别靠“运动方式”区分——五条偏**吸引、压缩、明亮、空间被拉弯**，宿傩偏**切割、干燥、短促、锋利**。不要给所有招式都套同一种“魔法嗡声”。

以下参数以 44.1 或 48 kHz 离线合成、最终单声道为例。频率和时长都是可起步的范围，不是唯一解；音高按实际听感再微调。

## 五条悟

| 招式 | 声音描述与合成配方 |
|---|---|
| **无下限：攻击被挡住** | 不要做成普通格挡“铛”。攻击接触前做 20–35 ms 的窄带上滑嘶声，接触点用 15–25 ms 玻璃感正弦/三角波“叮”，主体是 100–180 ms 的低通噪声凹陷，仿佛冲击被吸收；尾音留 250–450 ms 的高频细环鸣并快速变暗。标志是**尖端被截断、低频冲击缺席**。接触瞬间可短暂反转相位或下挖 6–10 dB，形成“不接触”的错觉。 |
| **苍：吸引** | 先是向内收的气流：带通噪声从约 1.8 kHz 向 350 Hz 下扫，80–160 ms；加一个 55–90 Hz 正弦低鸣从弱到强，再叠加 2–3 个高次谐波。主体不要“爆炸”，而是 250–500 ms 的吸入式轰鸣，末端用反向包络快速收口。循环环境层可做 5–8 Hz 振幅颤动，深度轻。 |
| **赫：排斥／爆发** | 苍的“向内”变成反向推出：5–15 ms 噪声瞬态，随后 30–70 ms 的 80–130 Hz 低频脉冲；主体 100–220 ms 带失真噪声，低通截止从 1 kHz 快速上扫到 4–6 kHz。尾音 180–300 ms，做短混响但削低频。与苍的区别在于**明确向外的瞬态和骤然张开的高频**。 |
| **虚式·茈：合成、发射、贯穿** | 三段不可糊成一个音。合成：苍的吸入低鸣和赫的高频张力并行 300–600 ms，在末段逐渐拍频（两振荡器差 2–6 Hz）；发射：10–25 ms 白噪声尖峰加 50–100 ms 低频冲击；贯穿：持续 180–350 ms 的中高频锯齿/噪声束，滤波中心由 1.2 kHz 上滑至 5 kHz，并做轻微脉冲门控；击中末端再给 250–500 ms 的低频坍塌和稀薄尾音。手机喇叭上用 120–250 Hz 的失真谐波补“重量”，不要依赖 40 Hz 以下。 |
| **无量空处：领域展开／被困住** | 展开不是单次爆炸：20 ms 低频起音后，做 150–300 ms 的宽带吸空/静音凹陷，接 1–2 秒的稀薄高音层。被困状态用 2–4 个微弱正弦音（例如 420、630、940 Hz）缓慢漂移、轻微失谐，配 0.3–0.8 Hz 慢振幅起伏；高频带限在约 6–8 kHz，避免刺耳。解除时用短促反向吸气加 80–120 ms 低频断点。签名是**宏大展开后，细节骤然稀薄、时间感停住**。 |
| **瞬移** | 6–12 ms 高频“掠过”加 30–60 ms 低频反向吸气；落点补 40–80 ms 的低中频闷击。若空间位移明显，声像可从一侧短扫到另一侧，但要用快速、克制的 pan，不要每帧随机移动。单声道版可用音高下滑替代声像。 |
| **黑闪** | 先给极短（5–12 ms）的干净拳击瞬态，再在 20–50 ms 后补一声 30–60 ms 的失真裂纹；加 80–150 ms 的窄带空间“折断”下坠音，约 2 kHz 滑到 300–500 Hz。黑闪的标识不是长电弧，而是**打击之后才出现的短暂断层**。 |
| **体术打击** | 拳脚主体做 3 层：2–8 ms 噪声点击；30–70 ms 的 80–160 Hz 衰减正弦；60–140 ms 的带通布料／风压噪声。轻击缩短低频层并降低 3–5 dB；重击加低频和 100–180 ms 房间尾音。 |
| **念咒／咏唱低鸣** | 以低音正弦或三角波为底，加 2、3、5 倍频的弱谐波，做 0.5–2 秒缓慢上升的滤波噪声；每个音节可加 20–40 ms 软起音，不需要复制角色声音。咏唱越接近释放，逐渐收窄频带、提高 1–3 kHz 谐波并增加 3–6 Hz 颤动。 |

## 两面宿傩

| 招式 | 声音描述与合成配方 |
|---|---|
| **解：无形斩击** | 重点是“斩到后才知道发生了”：3–8 ms 的极短高频切口（带通噪声 3–7 kHz），随后 25–60 ms 的低中频薄裂声。避免明显的长飞行音；若需要提示，可在命中前 20–40 ms 加极轻的 1.5–3 kHz 窄带下滑。多段斩击的间隔用 35–90 ms 错开，音色微随机但固定种子，别堆成持续白噪声。 |
| **捌** | 比“解”更厚、更近：短促 8–15 ms 起音，主体加 100–220 Hz 低中频切裂，尾巴 80–140 ms。用两条窄带噪声分别强调 700–1,200 Hz 的肉感和 3–5 kHz 的锋刃。若机制是贴身近战，减少空气飞行声。 |
| **世界斩** | 做成三步提示：极短的空间静止／高频下挖（20–40 ms）；随后一条 80–160 ms 极薄的宽带切线，中心频率快速横扫；最后 150–300 ms 的低音裂隙和短混响。不要做成更大的普通斩击；其签名应是**空间先被划线，环境声再像被切开一样断掉**。 |
| **领域展开·伏魔御厨子** | 神龛出现：低频木石共振（约 70–130 Hz）加 200–500 Hz 粗糙谐波，起音 100–250 ms，叠一记 2–5 kHz 干燥金属／木质撞击。无差别斩击层：短切口噪声成簇，单次 20–70 ms，簇间隔 60–160 ms；底下持续低鸣 150–400 Hz。领域尾声做 300–700 ms 的干燥衰减，别用太长大厅混响，否则连续斩击会糊。 |
| **领域展延** | 做成贴身的薄膜感：持续的带通噪声（约 500 Hz–3 kHz），低频很少，起音 50–100 ms，缓慢起伏；命中时膜层突然缺口 30–60 ms，再回填。音量应明显低于领域展开，以免和技能攻击争主位。 |
| **反转术式** | 不要用“治疗铃铛”式泛化提示。以 250–500 Hz 柔和正弦上行、叠 1–2 kHz 细亮谐波，起音 40–80 ms，尾音 250–600 ms；通过谐波从不和谐滑到和谐表达修复。若要对应宿傩的压迫感，低频底色保持暗，但高频不要刺。 |
| **十种影法术：嵌合兽顎吐电击** | 电击用 2–4 个 5–15 ms 电弧噪声脉冲，间距 25–70 ms；主体加 100–180 ms 低频脉冲。噪声带通中心从 1 kHz 上跳到 4–6 kHz，再快速掉回 1 kHz；轻微采样保持式阶梯失真可制造“电”的粗糙度。 |
| **魔虚罗召唤：布瑠部由良由良、法阵转动** | 召唤底鸣 1–2 秒，采用低音脉冲（50–90 Hz）和稀疏高次谐波；每个咏唱节拍加一个 80–140 Hz 的低沉敲击。法阵转动用 3–5 个齿位的金属摩擦／噪声脉冲，逐渐加速，最后以一声 8–20 ms 的干脆“咔”作为锁止点；用相位调制或短延迟（5–12 ms）做齿轮错位感。**“咔”是标识点，应突出而且短。** |
| **退魔之剑** | 起剑时给 30–60 ms 金属拔出声，主音 1.5–3.5 kHz；命中加 40–100 ms 的宽带斩击和 100–180 Hz 的闷冲击。尾音留 150–300 ms 的明亮金属鸣，但快速低通，避免拖成普通剑鸣。 |
| **开：火焰** | 20–50 ms 的火星噪声起音，主体用滤波噪声从 500 Hz 上升到 2–4 kHz，叠 70–120 Hz 热压低鸣；火焰喷出 120–250 ms，命中再给 100–200 ms 爆燃尾音。若要有蓄势，前置低频脉冲逐渐加快，发射瞬间留 10–20 ms 的短静隙。 |

## 领域展开通用设计

建议把领域展开做成**固定的三段式签名**，各角色只替换音色：

1. **结印／锁定（80–250 ms）**：2–4 个节奏递进的短音，最后一个略低或略高形成“已锁定”。五条偏清亮正弦谐波，宿傩偏木金属敲击与干噪。
2. **空间翻转（150–400 ms）**：低频下沉＋高频抽空；用反向包络噪声、滤波扫频、短暂静音制造空间折叠。避免纯粹加大音量。
3. **领域成形与对撞**：领域底床以 100–500 Hz 为主、低音量循环；对撞瞬间两组不同音高的谐波相互拍频，加入 20–40 ms 的低频冲击，再让一方底床被侧链式压低 100–250 ms。这样听者能听出“势均力敌／一方压过另一方”。

# B. 格斗游戏打击设计

- **轻／中／重分层**：轻击以 transient 为主（2–8 ms 点击、总长 70–120 ms）；中击提高 body（低中频 40–100 ms、总长 120–220 ms）；重击才明显增加 sub/body 与 tail（总长 250–500 ms）。不要只靠整体音量区分重量。
- **命中停顿同步**：hitstop 常见做法是命中帧冻结画面约 40–100 ms，重击更长；音效瞬态应落在命中帧，低频主体可晚 5–15 ms，尾音在冻结结束后继续衰减。若音频延迟导致起音落在恢复帧，玩家会觉得“拳没打中”。用战斗逻辑的同一命中事件触发，不要从动画结束回调触发。
- **格挡与命中分开**：格挡更短、更亮、更窄带，常用 1.5–4 kHz 金属／能量点击，低频少；命中加 80–180 Hz body 和更长尾音。完美格挡可额外加一个清晰短音，但不能跟普通格挡混淆。
- **前摇提示**：蓄力用稳定持续层（音量或脉冲密度递增），咏唱用有音高的谐波逐渐靠拢；释放前留 20–60 ms 的短空隙，再击发。蓄力越长，提示最好越有节拍或层次，避免玩家把背景音当成提示。
- **避免连击糊团**：同类轻击 60–100 ms 内可做声部限额／合并；重复击打随机微调音高 ±2–4%、音量 ±1–2 dB；多击时只让每隔一击或最后一击保留低频 body，其他击削掉 120 Hz 以下。高频疲劳可用 3–5 kHz 动态压低；同一招式重复播放时不要每次叠完整混响。

# C. Android 纯 Java 音频工程

| 项目 | 建议 |
|---|---|
| **SoundPool 用途与延迟** | SoundPool 适合短、已预加载的游戏 SFX；载入时会解码到 PCM，避免播放时临时解码，但不能把它理解为“零延迟”。SoundPool 文档说明其为低延迟用途，单个解码音效内部有约 1 MB 上限（44.1 kHz 双声道约 5.6 秒，单声道可更长）。见[官方 SoundPool 文档](https://developer.android.com/reference/android/media/SoundPool)。 |
| **maxStreams** | `SoundPool.Builder().setMaxStreams(16)` 可作起点；轻击密集时测试 16–24，避免无限增大。超过上限时会按优先级、再按播放时间停止旧流。给必杀／领域／命中音更高 priority，轻击低一些；priority 是 `play()` 的参数。 |
| **格式与采样率** | 短 SFX 优先 OGG Vorbis（体积小）或 WAV/PCM（解码简单、编辑方便）；SoundPool 会在载入时解码，选择时以兼容性和资源体积为准。合成母版保留 48 kHz 浮点，导出可统一 44.1 kHz 或 48 kHz；手机混音最终会走设备输出采样率，统一采样率主要是资产管理便利，不保证延迟更低。战斗 SFX 多数用单声道，可节省内存并保持定位一致；宽阔领域底床可做立体声，但应另做单声道兼容检查。 |
| **预加载** | 加载界面／战斗场景前调用 `load()`，用 `OnLoadCompleteListener` 确认 sample 已载入再开放战斗；别在命中事件里 `load()`。SoundPool 文档也建议早载入，让解码有时间完成。 |
| **play 的 rate / pan / priority** | `play(soundId, leftVolume, rightVolume, priority, loop, rate)` 中音量范围为 0–1；左右音量可用于定位，`rate` 改变播放速率与音高。常用 rate 0.97–1.03 做轻微变体，超过 1.1 容易明显变调；同一音效用少量预渲染变体通常比大幅调速自然。`setRate(streamId, rate)` 可用于播放中调整。官方参考：[SoundPool API](https://developer.android.com/reference/android/media/SoundPool)。 |
| **手机小喇叭** | 不要让重量依赖 60 Hz 以下；许多手机外放在约 150–250 Hz 以下已明显衰减，具体随机型变化。用 100–250 Hz 的 body 加 2、3、4 倍谐波、轻度饱和，让小喇叭仍听出“厚”。技能提示的关键音放在约 700 Hz–4 kHz；高频细节控制峰值，避免 3–6 kHz 连续尖锐。 |
| **与 MediaPlayer 背景音乐混音** | 用主音量总线管理，不把 MediaPlayer 的音量当唯一混音器。可从 BGM 峰值比常规命中低约 8–12 dB 起步；必杀触发时 BGM 再 duck 3–6 dB，释放后 300–700 ms 恢复。SFX 保留瞬态余量，避免总线削波；不同手机外放实听校准比固定比例可靠。 |
| **焦点与切后台** | 游戏前台时按 `AudioAttributes.USAGE_GAME` 请求焦点；失焦时暂停或 duck BGM，SFX 通常直接停；返回前台再按状态恢复。Android 8.0–11 请求焦点要用 `AudioFocusRequest`；Android 12/API 31 起系统会强制部分失焦淡出行为；针对 Android 15/API 35+ 的应用，只有前台或运行前台服务时才能请求焦点。见[官方音频焦点说明](https://developer.android.com/media/optimize/audio-focus)。 |
| **版本注意** | API 21+ 可用 `SoundPool.Builder` 和 `AudioAttributes`；旧版本需兼容旧构造器。API 26+ 焦点请求 API 变化；API 31+ 系统管理焦点更强；API 35+ 有前台请求限制。游戏切后台通常应暂停/释放 BGM，避免把游戏音频做成意外后台播放。 |

# 建议的统一风格与响度目标

把五条的“空间弯曲感”和宿傩的“切口感”作为对比主轴：共同底色是低鸣＋噪声，五条的音效更有吸入、滑音和明亮谐波；宿傩更干、短、偏木金属和窄带切口。所有技能保留清晰 transient，避免长混响；领域底床可以宽，命中音要近、干。

以**常规中击的短时峰值 = 0 dB 相对基准**，先按这个比例混音，再整体做响度／峰值管理：

- 轻击：−4 至 −2 dB
- 中击：0 dB
- 重击：+2 至 +4 dB
- 格挡：−2 至 +1 dB，但减少低频、强调短亮瞬态
- 普通术式：+1 至 +3 dB
- 必杀／领域展开：+4 至 +6 dB；通过 BGM duck 获得显著性，不要把所有层都推到峰值
- 持续咏唱／领域底床：−8 至 −4 dB
- 命中尾音与混响：比主体低至少 6–12 dB

总线建议留 **至少 1 dBTP** 的真峰值余量；关键是同一设备上技能等级清楚、连击不刺耳、外放能听到中频信息。把上表当作混音起点，而不是标准响度规范。
